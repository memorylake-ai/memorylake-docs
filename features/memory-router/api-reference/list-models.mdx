---
title: "List Models"
description: "List the models you can call and their prices"
---

```
GET /openapi/memorylake/router/v1/models
```

Lists the models you can call through Memory Router, with their prices, sorted by name. `provider_type` tells you which base URL reaches each model: call `openai` models through `/router/openai/v1` and `anthropic` models through `/router/anthropic/v1`. Image models carry `kind: image_generation` and are called through `/router/openai/v1/images/generations`; chat models have no `kind`. Each site has its own catalog.

Unlike the inference endpoints, this endpoint answers in the MemoryLake API format: the catalog is in `data.items`, and errors carry `success`, `message` and `error_code`.

Prices are per million tokens, in US dollars and in balance tokens (what your balance is charged). A price that is not listed does not apply to the model; it is not free. When `price` is missing, no price is available for the model; it can still be called.

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.ai/openapi/memorylake/router/v1/models' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### Errors

Errors answer with `success: false`, a `message` and an `error_code`. See [Error Codes](/features/memorylake/api-reference/errors) for every code.

| Status | Meaning |
| --- | --- |
| `401` | The MemoryLake API key is missing, invalid, disabled or expired. `error_code` is `UNAUTHORIZE`. |
| `403` | The key may only be used from listed IP addresses, and this request came from another one. `error_code` is `ACCESS_DENIED`. |
| `429` | Too many requests with an invalid key came from your IP address. `error_code` is `RATE_LIMIT_EXCEEDED`. Wait for the time in `Retry-After`. |
| `502` | The model catalog could not be loaded. `error_code` is `INTERNAL_ERROR`. Retry later. |
| `503` | The service is temporarily unavailable, for example during maintenance. `error_code` is `SERVICE_UNAVAILABLE`. Retry later; `Retry-After` is sent when the wait is known. |
