---
title: "List Models"
description: "List the models you can call and their prices"
---

```
GET /openapi/memorylake/router/v1/models
```

Lists the models you can call through Memory Router, with their prices, grouped by protocol: call `openai` models through `/router/openai/v1` and `anthropic` models through `/router/anthropic/v1`. Each site has its own catalog.

Prices are per million tokens, in US dollars and in balance tokens (what your balance is charged). A price that is not listed does not apply to the model; it is not free. When `price` is missing, no price is available for the model; it can still be called.

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.ai/openapi/memorylake/router/v1/models' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>
