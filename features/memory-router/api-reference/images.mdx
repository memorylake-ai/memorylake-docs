---
title: "Images"
description: "Generate images with OpenAI image models"
---

```
POST /openapi/memorylake/router/openai/v1/images/generations
```

OpenAI Images. Generates images from a text prompt with an image model such as `gpt-image-1`. Parameters not listed below are passed to the model unchanged.

### Headers

<ParamField header="x-memorylake-api-key" type="string">
Your MemoryLake API key, when you call the model with your own provider key. The provider key then goes in the provider's usual key header. Your provider key is forwarded to the provider and never stored.
</ParamField>

<ParamField header="traceparent" type="string">
W3C trace context. When present, the request joins your trace and the same trace id comes back in `X-Trace-ID`.
</ParamField>

### Request Body

<ParamField body="model" type="string" required>
Image model name
</ParamField>

<ParamField body="prompt" type="string" required>
Text description of the image
</ParamField>

<ParamField body="background" type="string">
Background of the image. One of: `transparent`, `opaque`, `auto`.
</ParamField>

<ParamField body="n" type="integer">
Number of images to generate
</ParamField>

<ParamField body="output_format" type="string">
Image file format. One of: `png`, `jpeg`, `webp`.
</ParamField>

<ParamField body="quality" type="string">
Rendering quality. One of: `low`, `medium`, `high`, `auto`.
</ParamField>

<ParamField body="size" type="string">
Image size, such as `1024x1024`
</ParamField>

<RequestExample>
```bash cURL
curl -X POST 'https://app.memorylake.ai/openapi/memorylake/router/openai/v1/images/generations' \
  -H 'Authorization: Bearer sk_xxxxxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "gpt-image-1-mini",
    "prompt": "A small red circle on a white background",
    "quality": "low",
    "size": "1024x1024"
  }'
```
</RequestExample>

### Response

<ResponseField name="created" type="integer">Creation time, Unix seconds</ResponseField>
<ResponseField name="data" type="array">
One entry per image
<Expandable title="Data object">
  <ResponseField name="b64_json" type="string">The image, base64-encoded</ResponseField>
  <ResponseField name="revised_prompt" type="string">Prompt the model actually used, when it rewrote yours</ResponseField>
</Expandable>
</ResponseField>
<ResponseField name="usage" type="object">
Tokens used
<Expandable title="Usage object">
  <ResponseField name="input_tokens" type="integer">Tokens in the prompt</ResponseField>
  <ResponseField name="output_tokens" type="integer">Image tokens generated</ResponseField>
  <ResponseField name="total_tokens" type="integer">Sum of input and output tokens</ResponseField>
</Expandable>
</ResponseField>

```json Success (200)
  }
}
```
</ResponseExample>
