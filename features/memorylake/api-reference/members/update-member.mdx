---
title: "Update Member"
description: "Changes a member's role and/or per-member usage cap"
---

```
PATCH /openapi/memorylake/admin/v1/members/{principal_id}
```

Changes a member's role and/or per-member usage cap. Only the fields you send change; null is rejected. The owner role cannot be assigned here, and the owner's own role and your own role cannot be changed — use [Transfer Ownership](/features/memorylake/api-reference/team/transfer-ownership) to hand the team to another member. You can only change members ranked below you: an admin cannot change another admin, and nobody but the owner can change an admin (403 MEMBER_NOT_BELOW_CALLER) — the role and the usage cap alike. An admin-level role (GET /roles, admin_grant_only) can be granted only by the owner (403 ROLE_REQUIRES_OWNER) and never to a virtual member (400 ROLE_NOT_FOR_VIRTUAL_MEMBER). The same rules apply in the console.

<Note>
**Permission required:** depends on what you send:

- When you send `role`: `member:change_role`
- When you send `max_tokens`: `member:set_quota`
- When the role assigned is admin-level: tenant_admin, or a custom role holding any admin-only team action: team owner only
- When the member is not ranked below you: the owner, an admin, or a holder of an admin-level custom role (403 MEMBER_NOT_BELOW_CALLER) — role and max_tokens alike: team owner only
</Note>

### Path Parameters

<ParamField path="principal_id" type="string" required>
Identifier of the member (`principal_id`)
</ParamField>

### Headers

<ParamField header="Idempotency-Key" type="string">
Optional. Retrying with the same value replays the first result.
</ParamField>

### Request Body

<ParamField body="max_tokens" type="integer">
Per-member usage cap in tokens, at most 1374389534. 0 removes the cap.
</ParamField>

<ParamField body="role" type="string">
New role: tenant_admin, tenant_member, or a custom role key of this team. The owner role cannot be assigned here.
</ParamField>

<RequestExample>
```bash cURL
curl -X PATCH 'https://app.memorylake.ai/openapi/memorylake/admin/v1/members/dbcf9a3aabee5042775269c9d137a2f8' \
  -H 'Authorization: Bearer sk_xxxxxx' \
  -H 'Idempotency-Key: 7c1d2e3f-0a9b-4c8d-b7e6-f5a4d3c2b1a0' \
  -H 'Content-Type: application/json' \
  -d '{
    "max_tokens": 1200000,
    "role": "tenant_member"
  }'
```
</RequestExample>
