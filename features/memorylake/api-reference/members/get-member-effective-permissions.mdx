---
title: "Get Member Effective Permissions"
description: "Returns what the member can do and where each permission comes from: the role, access groups, or a direct grant"
---

```
GET /openapi/memorylake/admin/v1/members/{principal_id}/effective-permissions
```

Returns what the member can do and where each permission comes from: the role, access groups, or a direct grant.

<Note>
**Permission required:** `access_group:view`
</Note>

### Path Parameters

<ParamField path="principal_id" type="string" required>
Identifier of the member (`principal_id`)
</ParamField>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.ai/openapi/memorylake/admin/v1/members/dbcf9a3aabee5042775269c9d137a2f8/effective-permissions' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>
