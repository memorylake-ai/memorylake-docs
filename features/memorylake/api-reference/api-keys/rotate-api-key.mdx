---
title: "Rotate API Key"
description: "Replaces the key material and returns the new value once"
---

```
POST /openapi/memorylake/admin/v1/api-keys/{id}/rotate
```

Replaces the key material and returns the new value once. The previous value stops working immediately.

<Warning>
Rotation is not naturally idempotent: every call mints a new key and stops the previous one. When retrying over an unreliable network, always send an `Idempotency-Key` — a blind retry would invalidate the key you just received.
</Warning>

<Note>
**Permission required:** `service_account:update` (your own keys only) or `service_account:update` (all keys)
</Note>

### Path Parameters

<ParamField path="id" type="string" required>
Identifier of the API key
</ParamField>

### Headers

<ParamField header="Idempotency-Key" type="string">
Optional. Retrying with the same value replays the first result — it does NOT mint a second key.
</ParamField>

<RequestExample>
```bash cURL
curl -X POST 'https://app.memorylake.ai/openapi/memorylake/admin/v1/api-keys/9d971b8b5813eb1ecceec31354c101b4/rotate' \
  -H 'Authorization: Bearer sk_xxxxxx' \
  -H 'Idempotency-Key: 7c1d2e3f-0a9b-4c8d-b7e6-f5a4d3c2b1a0'
```
</RequestExample>

### Response

<ResponseField name="data" type="object">
<Expandable title="API Key Created object">
  <ResponseField name="id" type="string">Stable identifier of this API key</ResponseField>
  <ResponseField name="key" type="string">The full API key, including the sk- prefix. Save it now — read endpoints never return it.</ResponseField>
  <ResponseField name="key_prefix" type="string">First 8 characters of the key body</ResponseField>
  <ResponseField name="name" type="string">Display name</ResponseField>
  <ResponseField name="key_suffix" type="string">Last 4 characters of the key</ResponseField>
</Expandable>
</ResponseField>
