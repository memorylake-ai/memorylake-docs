---
title: "List Auto Top-Up Attempts"
description: "Lists automatic top-up attempts, newest first — including failed ones, which may have no order"
---

```
GET /openapi/memorylake/admin/v1/billing/auto-topup/attempts
```

Lists automatic top-up attempts, newest first — including failed ones, which may have no order.

<Note>
**Permission required:** `credits:view`
</Note>

### Query Parameters

<ParamField query="page_size" type="integer" default="20">
Items per page (1–100)
</ParamField>

<ParamField query="continuation_token" type="string">
Token from the previous page
</ParamField>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.ai/openapi/memorylake/admin/v1/billing/auto-topup/attempts' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### Response

<ResponseField name="data" type="object">
<Expandable title="Load More Response Auto Topup Attempt object">
  <ResponseField name="items" type="array">
  List of items in the current page
  <Expandable title="Auto Topup Attempt object">
    <ResponseField name="amount" type="object">
    Amount charged (or attempted)
    <Expandable title="Money object">
      <ResponseField name="amount" type="integer">Amount in the currency's smallest unit (cents for usd)</ResponseField>
      <ResponseField name="currency" type="string">Lowercase ISO 4217 currency code</ResponseField>
    </Expandable>
    </ResponseField>
    <ResponseField name="created_at" type="integer">Unix seconds</ResponseField>
    <ResponseField name="failure_reason" type="string">Why it failed; null unless status is failed. payment_method_missing = no card on file; payment_failed = the payment provider declined or could not complete the charge; processing_error = the charge could not be set up</ResponseField>
    <ResponseField name="id" type="integer">Attempt id</ResponseField>
    <ResponseField name="order_id" type="string">The order created for the charge (GET /billing/orders/\{order_id\}); null when none was created</ResponseField>
    <ResponseField name="status" type="string">Outcome of the attempt. One of: `pending`, `succeeded`, `failed`, `refunded`.</ResponseField>
    <ResponseField name="tokens" type="integer">Tokens the top-up adds when it succeeds</ResponseField>
    <ResponseField name="triggered_by" type="string">What started it. One of: `balance_check`, `manual`.</ResponseField>
    <ResponseField name="updated_at" type="integer">Unix seconds</ResponseField>
  </Expandable>
  </ResponseField>
  <ResponseField name="continuation_token" type="string">Token to fetch the next page; absent on the last page</ResponseField>
  <ResponseField name="total" type="integer">Total number of items matching the filter across all pages; omitted when the count is unavailable</ResponseField>
</Expandable>
</ResponseField>
