```
GET /openapi/memorylake/admin/v1/billing/subscription/plan-change-preview
```

Prices switching the subscription to plan_id without changing anything: the prorated amount charged now, its line items, when the change takes effect and the next full invoice. proration_date echoes the instant the proration was computed for. Switches that cost nothing come back with applicable false and a reason. Changing the plan itself is done in the console.

<Note>
**Permission required:** `subscription:manage`
</Note>

### Query Parameters

<ParamField query="plan_id" type="integer" required>
The plan to price a switch to
</ParamField>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.ai/openapi/memorylake/admin/v1/billing/subscription/plan-change-preview?plan_id=9e50b1aed525a8280e28b9662b6a7ba0' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>
