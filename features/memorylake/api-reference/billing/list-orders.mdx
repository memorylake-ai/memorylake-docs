---
title: "List Orders"
description: "Lists the team's payment orders, newest first, optionally by type and status"
---

```
GET /openapi/memorylake/admin/v1/billing/orders
```

Lists the team's payment orders, newest first, optionally by type and status.

<Note>
**Permission required:** `order:read`
</Note>

### Query Parameters

<ParamField query="type" type="string">
Only orders of this type. One of: `onetime`, `auto_topup`, `subscription`.
</ParamField>

<ParamField query="status" type="string">
Only orders in this state. One of: `pending`, `succeeded`, `failed`, `closed`, `refunded`, `disputed`.
</ParamField>

<ParamField query="page_size" type="integer" default="20">
Items per page (1–100)
</ParamField>

<ParamField query="continuation_token" type="string">
Token from the previous page
</ParamField>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.ai/openapi/memorylake/admin/v1/billing/orders' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

    <ResponseField name="created_at" type="integer">Unix seconds</ResponseField>

    <ResponseField name="type" type="string">onetime = a credit purchase; auto_topup = an automatic top-up charge; subscription = a subscription payment</ResponseField>
