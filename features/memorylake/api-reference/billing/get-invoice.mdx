---
title: "Get Invoice"
description: "Returns one invoice"
---

```
GET /openapi/memorylake/admin/v1/billing/invoices/{invoice_id}
```

Returns one invoice. Invoices of other teams are reported as not found.

<Note>
**Permission required:** `invoice:read`
</Note>

### Path Parameters

<ParamField path="invoice_id" type="string" required>
Invoice id (`invoice_id`)
</ParamField>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.ai/openapi/memorylake/admin/v1/billing/invoices/2501a637ff332794f7dc5edee0556e67' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### Errors

Errors answer with `success: false`, a `message` and an `error_code`. See [Error Codes](/features/memorylake/api-reference/errors) for every code.

| Status | Meaning |
| --- | --- |
| `401` | The API key is missing, invalid, disabled or expired |
| `403` | The key is not allowed to do this |
| `404` | The resource does not exist |
| `422` | The body or a parameter failed validation |
| `429` | Too many requests. Wait for the time in `Retry-After` |
| `500` | Server-side error |
