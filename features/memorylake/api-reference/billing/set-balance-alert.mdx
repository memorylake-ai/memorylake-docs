---
title: "Set Low-Balance Alert"
description: "Replaces the low-balance alert configuration"
---

```
PUT /openapi/memorylake/admin/v1/billing/credit-balance/alert
```

Replaces the low-balance alert configuration. Thresholds are all percent_used or all tokens_remaining (at most 5); absolute levels are in tokens. Recipients are added to the team owner, who is always notified. To stop alerts, set enabled to false.

<Note>
**Permission required:** `credits:manage`
</Note>

### Request Body

<ParamField body="enabled" type="boolean" required>
Whether alerts are sent
</ParamField>

<ParamField body="thresholds" type="array" required>
Alert levels, all of one type; duplicates are dropped
<Expandable title="Balance Alert Threshold object">
  <ParamField body="thresholds[].type" type="string" required>Threshold type; every threshold in one request must share it. One of: `percent_used`, `tokens_remaining`.</ParamField>
  <ParamField body="thresholds[].value" type="integer" required>1–99 for percent_used; 1–1,000,000,000 for tokens_remaining</ParamField>
</Expandable>
</ParamField>

<ParamField body="notification_channel" type="object">
Omit to send to the team owner only
<Expandable title="Alert Recipients Channel object">
  <ParamField body="notification_channel.recipients" type="array" required>Additional addresses (the team owner always receives alerts); duplicates are dropped case-insensitively</ParamField>
  <ParamField body="notification_channel.type" type="string" required>Delivery channel. One of: `email`.</ParamField>
</Expandable>
</ParamField>

<RequestExample>
```bash cURL
curl -X PUT 'https://app.memorylake.ai/openapi/memorylake/admin/v1/billing/credit-balance/alert' \
  -H 'Authorization: Bearer sk_xxxxxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "enabled": true,
    "thresholds": [
      {
        "type": "percent_used",
        "value": 1
      }
    ],
    "notification_channel": {
      "recipients": [
        "example"
      ],
      "type": "email"
    }
  }'
```
</RequestExample>

  <ResponseField name="notification_channel" type="object">
  Where alerts go

  </ResponseField>
  <ResponseField name="status" type="object">

    <ResponseField name="state" type="string">triggered = an alert has fired and the balance has not recovered above its level yet. One of: `ok`, `triggered`.</ResponseField>

    <ResponseField name="threshold" type="object">
    The level that fired

      <ResponseField name="value" type="integer">1–99 for percent_used; 1–1,000,000,000 for tokens_remaining</ResponseField>
    </Expandable>
    </ResponseField>
    <ResponseField name="triggered_at" type="integer">When the active alert fired, Unix seconds</ResponseField>
  </Expandable>
  </ResponseField>
  <ResponseField name="thresholds" type="array">
  Alert levels; all of one type
  <Expandable title="Balance Alert Threshold object">
    <ResponseField name="type" type="string">percent_used = alert when the share of the subscription cycle (or, without a subscription, of all credit ever added) used reaches value percent; tokens_remaining = alert when the balance falls to value tokens</ResponseField>
    <ResponseField name="value" type="integer">1–99 for percent_used; 1–1,000,000,000 for tokens_remaining</ResponseField>
  </Expandable>
  </ResponseField>
</Expandable>
</ResponseField>
