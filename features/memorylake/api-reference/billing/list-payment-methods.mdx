---
title: "List Payment Methods"
description: "Lists the saved cards: brand, last four digits, expiry and which one is the default"
---

```
GET /openapi/memorylake/admin/v1/billing/payment-methods
```

Lists the saved cards: brand, last four digits, expiry and which one is the default. Adding, removing and choosing the default are done in the console.

<Note>
**Permission required:** `credits:manage`
</Note>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.ai/openapi/memorylake/admin/v1/billing/payment-methods' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### Errors

Errors answer with `success: false`, a `message` and an `error_code`. See [Error Codes](/features/memorylake/api-reference/errors) for every code.

| Status | Meaning |
| --- | --- |
| `401` | The API key is missing, invalid, disabled or expired |
| `403` | The key is not allowed to do this |
| `429` | Too many requests. Wait for the time in `Retry-After` |
| `500` | Server-side error |
| `503` | Temporarily unavailable. Retry later |
