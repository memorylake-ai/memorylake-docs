---
title: "List Invoices"
description: "Lists the team's invoices, newest first, optionally by state"
---

```
GET /openapi/memorylake/admin/v1/billing/invoices
```

Lists the team's invoices, newest first, optionally by state.

<Note>
**Permission required:** `invoice:read`
</Note>

### Query Parameters

<ParamField query="status" type="array">
Repeatable. Only invoices in these states
</ParamField>

<ParamField query="page_size" type="integer" default="20">
Items per page (1–100)
</ParamField>

<ParamField query="continuation_token" type="string">
Token from the previous page
</ParamField>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.ai/openapi/memorylake/admin/v1/billing/invoices' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>
