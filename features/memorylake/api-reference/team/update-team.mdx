---
title: "Rename Team"
description: "Updates the team's display name"
---

```
PATCH /openapi/memorylake/admin/v1/team
```

Updates the team's display name. Only the team owner may do this — the same rule the console applies.

<Note>
**Permission required:** team owner only
</Note>

### Headers

<ParamField header="Idempotency-Key" type="string">
Optional. Retrying with the same value replays the first result.
</ParamField>

### Request Body

<ParamField body="name" type="string" required>
New display name for the team
</ParamField>

<RequestExample>
```bash cURL
curl -X PATCH 'https://app.memorylake.ai/openapi/memorylake/admin/v1/team' \
  -H 'Authorization: Bearer sk_xxxxxx' \
  -H 'Idempotency-Key: 7c1d2e3f-0a9b-4c8d-b7e6-f5a4d3c2b1a0' \
  -H 'Content-Type: application/json' \
  -d '{
    "name": "Example name"
  }'
```
</RequestExample>

### Response

<ResponseField name="data" type="object">
<Expandable title="Team object">
  <ResponseField name="created_at" type="integer">Creation time, Unix seconds</ResponseField>
  <ResponseField name="id" type="string">Stable identifier of this team</ResponseField>
  <ResponseField name="name" type="string">Display name</ResponseField>
  <ResponseField name="owner_principal_id" type="string">principal_id of the team owner (see the members list)</ResponseField>
  <ResponseField name="type" type="string">personal = single-user space, org = team with members</ResponseField>
  <ResponseField name="caller_role" type="string">The calling key's role in this team: tenant_owner | tenant_admin | tenant_member | &lt;custom role&gt;</ResponseField>
</Expandable>
</ResponseField>

Errors answer with `success: false`, a `message` and an `error_code`. See [Error Codes](/features/memorylake/api-reference/errors) for every code.

| Status | Meaning |
| --- | --- |
| `401` | The API key is missing, invalid, disabled or expired |
| `403` | The key is not allowed to do this |
| `422` | The body or a parameter failed validation |
| `429` | Too many requests. Wait for the time in `Retry-After` |
| `500` | Server-side error |
| `503` | Temporarily unavailable. Retry later |
