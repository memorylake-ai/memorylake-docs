---
title: "Transfer Ownership"
description: "Transfers ownership of this org team to another active human member (not an API key, not a virtual member)"
---

```
POST /openapi/memorylake/admin/v1/team/transfer-ownership
```

Transfers ownership of this org team to another active human member (not an API key, not a virtual member). The caller becomes an admin and can no longer perform owner-only operations after the transfer, including this one. A retry with the same Idempotency-Key replays the first result to the same caller only; anyone else is refused. Another transfer of the same team in progress answers 409; retry.

<Warning>
**High-risk operation.** It takes effect immediately. Read what it changes, above, before you call it.
</Warning>

<Note>
**Permission required:** team owner only
</Note>

### Headers

<ParamField header="Idempotency-Key" type="string">
Optional. Retrying with the same value replays the first result for the same caller.
</ParamField>

### Request Body

<ParamField body="new_owner_principal_id" type="string" required>
principal_id of an active human member who will become the team owner
</ParamField>

<RequestExample>
```bash cURL
curl -X POST 'https://app.memorylake.ai/openapi/memorylake/admin/v1/team/transfer-ownership' \
  -H 'Authorization: Bearer sk_xxxxxx' \
  -H 'Idempotency-Key: 7c1d2e3f-0a9b-4c8d-b7e6-f5a4d3c2b1a0' \
  -H 'Content-Type: application/json' \
  -d '{
    "new_owner_principal_id": "670048c3ad268485e39c944bbf532eb8"
  }'
```
</RequestExample>
