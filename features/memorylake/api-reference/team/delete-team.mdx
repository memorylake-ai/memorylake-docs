---
title: "Delete Team"
description: "Permanently dissolves this org team; it cannot be undone"
---

```
DELETE /openapi/memorylake/admin/v1/team
```

Permanently dissolves this org team; it cannot be undone. All team API keys, including the key used for this request, stop working immediately, and every member loses access to the team. A paid subscription is cancelled immediately before deletion, without a refund for the current period; if the cancellation fails the team is left untouched (409). Personal teams cannot be deleted. No Idempotency-Key: once the team is gone, this key is rejected (401) before any replay — a retry answering 401, or [Get Team](/features/memorylake/api-reference/team/get-team) answering 401, means the team was deleted. A 500 that says the subscription was already cancelled can be retried.

<Warning>
**High-risk operation.** It takes effect immediately. Read what it changes, above, before you call it.
</Warning>

<Note>
**Permission required:** team owner only
</Note>

<RequestExample>
```bash cURL
curl -X DELETE 'https://app.memorylake.ai/openapi/memorylake/admin/v1/team' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### Response

<ResponseField name="data" type="object">
<Expandable title="Delete Team object">
  <ResponseField name="dissolved_at" type="integer">Deletion time, Unix seconds</ResponseField>
  <ResponseField name="subscription_canceled" type="boolean">true when a paid subscription was cancelled before deletion; false when there was no paid subscription</ResponseField>
  <ResponseField name="tenant_id" type="string">Deleted team id</ResponseField>
</Expandable>
</ResponseField>

<ResponseExample>
```json Success (200)
{
  "success": true,
  "message": "Operation completed successfully",
  "data": {
    "dissolved_at": 1760000000,

    "tenant_id": "a4d44d50a6ceaf6d613fd153dabea710"
  }

```
</ResponseExample>

### Errors

Errors answer with `success: false`, a `message` and an `error_code`. See [Error Codes](/features/memorylake/api-reference/errors) for every code.

| Status | Meaning |
| --- | --- |
| `401` | The API key is missing, invalid, disabled or expired |
| `403` | The key is not allowed to do this |
| `409` | The request conflicts with the current state, e.g. a duplicate or a limit reached |
| `429` | Too many requests. Wait for the time in `Retry-After` |
| `500` | Server-side error |
