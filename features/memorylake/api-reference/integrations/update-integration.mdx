---
title: "Update IM Integration"
description: "Changes an integration"
---

```
PATCH /openapi/memorylake/admin/v1/integrations/{integration_id}
```

Changes an integration. Only the fields you send change; null is rejected. Omit credentials to keep them; send only a new secret to rotate it. The bot's app identifier cannot change (422). New DingTalk, Feishu and Slack credentials are verified before saving, and the status returns to pending until the new connection is up. Changing a project reference needs the same project access as [Create IM Integration](/features/memorylake/api-reference/integrations/create-integration).

<Note>
**Permission required:** `workspace:integration_manage` on `workspace_id`

- When you set `read_write_project_id`: `project:mem_add` on `read_write_project_id`
- When you set `read_only_project_ids`: `project:mem_search` on `read_only_project_ids`
</Note>

### Path Parameters

<ParamField path="integration_id" type="string" required>
Identifier of the integration
</ParamField>

### Headers

<ParamField header="Idempotency-Key" type="string">
Optional. Retrying with the same value replays the first result. Credential values are not compared.
</ParamField>

### Request Body

<ParamField body="agent_id" type="string">
Switch the answering agent. Ongoing IM conversations start over with the new agent; sending the current agent_id changes nothing.
</ParamField>

<ParamField body="credentials" type="object">
Write-only. Omit to keep the stored credentials. Send only the values that change: a secret can be rotated alone. The app identifier (appKey / appId / botId, or the Slack team and bot user) cannot change — delete and recreate the integration to connect a different bot. DingTalk, Feishu and Slack credentials are verified with the platform before saving.
<Expandable title="Integration Credentials object">
  <ParamField body="credentials.appId" type="string">Feishu: App ID. Identifies the bot; cannot change after creation.</ParamField>
  <ParamField body="credentials.appKey" type="string">DingTalk: Client ID (AppKey). Identifies the bot; cannot change after creation.</ParamField>
  <ParamField body="credentials.appSecret" type="string">DingTalk: Client Secret (AppSecret). Feishu: App Secret.</ParamField>
  <ParamField body="credentials.appToken" type="string">Slack: App-Level Token (xapp-…) with connections:write.</ParamField>
  <ParamField body="credentials.botId" type="string">WeCom: Bot ID of the intelligent robot. Identifies the bot; cannot change after creation.</ParamField>
  <ParamField body="credentials.botToken" type="string">Slack: Bot User OAuth Token (xoxb-…). Apps with token rotation enabled are not supported.</ParamField>
  <ParamField body="credentials.secret" type="string">WeCom: Secret of the intelligent robot.</ParamField>
</Expandable>
</ParamField>

<ParamField body="daily_message_limit" type="integer">
Maximum messages handled per day; 0 = unlimited
</ParamField>

<ParamField body="dataset_ids" type="array">
Replace the datasets. [] removes them.
</ParamField>

<ParamField body="enabled" type="boolean">
Connect (true) or disconnect (false) the bot
</ParamField>

<ParamField body="name" type="string">
New display name
</ParamField>

<ParamField body="read_only_project_ids" type="array">
Replace the read-only projects. [] removes them.
</ParamField>

<ParamField body="read_write_project_id" type="string">
New project for extracted memories
</ParamField>

<ParamField body="settings" type="object">
Replace the channel-specific settings
<Expandable title="Integration Settings object">
  <ParamField body="settings.card_template_id" type="string">DingTalk only: AI card template id. Set it to stream replies into an interactive card; omit or send "" to reply with plain messages.</ParamField>
</Expandable>
</ParamField>

New codes may be added; treat an unrecognised one like connection_failed.</ResponseField>

### Errors

Errors answer with `success: false`, a `message` and an `error_code`. See [Error Codes](/features/memorylake/api-reference/errors) for every code.

| Status | Meaning |
| --- | --- |
| `400` | A parameter or the body is invalid |
| `401` | The API key is missing, invalid, disabled or expired |
| `403` | The key is not allowed to do this |
| `404` | The resource does not exist |
| `409` | The request conflicts with the current state, e.g. a duplicate or a limit reached |
| `422` | The body or a parameter failed validation |
| `429` | Too many requests. Wait for the time in `Retry-After` |
| `500` | Server-side error |
| `503` | Temporarily unavailable. Retry later |
