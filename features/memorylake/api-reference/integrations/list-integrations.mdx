---
title: "List IM Integrations"
description: "Lists the IM channel integrations in the workspaces you may manage, newest first"
---

```
GET /openapi/memorylake/admin/v1/integrations
```

Lists the IM channel integrations in the workspaces you may manage, newest first. Integrations in other workspaces are left out (and not counted in total); filtering by a workspace you may not manage is refused. Credentials are never returned.

<Note>
**Permission required:** depends on what you send:

- When you set `workspace_id`: `workspace:integration_manage` on `workspace_id`
</Note>

### Query Parameters

<ParamField query="page_size" type="integer" default="20">
Number of items per page (1–100)
</ParamField>

<ParamField query="continuation_token" type="string">
Token from the previous page. Opaque — do not construct or parse it.
</ParamField>

<ParamField query="workspace_id" type="string">
Only integrations of this workspace
</ParamField>

<ParamField query="agent_id" type="string">
Only integrations answered by this agent
</ParamField>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.ai/openapi/memorylake/admin/v1/integrations' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

New codes may be added; treat an unrecognised one like connection_failed.</ResponseField>

### Errors

Errors answer with `success: false`, a `message` and an `error_code`. See [Error Codes](/features/memorylake/api-reference/errors) for every code.

| Status | Meaning |
| --- | --- |
| `400` | A parameter or the body is invalid |
| `401` | The API key is missing, invalid, disabled or expired |
| `403` | The key is not allowed to do this |
| `404` | The resource does not exist |
| `422` | The body or a parameter failed validation |
| `429` | Too many requests. Wait for the time in `Retry-After` |
| `500` | Server-side error |
