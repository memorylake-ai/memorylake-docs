---
title: "Forget Actor Fact"
description: "Mark an actor-level fact as forgotten without deleting it"
---

```
POST /openapi/memorylake/api/v3/workspaces/{workspaceId}/actors/{actorId}/facts/{factId}/forget
```

Marks an actor-level fact as forgotten (expired) without permanently deleting it. The fact remains available for audit purposes but is excluded from future retrievals and searches. To forget multiple actor facts at once, use [Batch Forget Actor Facts](/features/memorylake/api-reference/facts/batch-forget-actor-facts).

<Note>
**Permission required:** `workspace_actor:fact_delete` on a person's memories, or `workspace_agent:fact_delete` on an agent's — whichever the id belongs to
</Note>

### Path Parameters

<ParamField path="workspaceId" type="string" required>
Workspace ID
</ParamField>

<ParamField path="actorId" type="string" required>
Actor ID
</ParamField>

<ParamField path="factId" type="string" required>
Fact ID to forget
</ParamField>

<RequestExample>
```bash cURL
curl -X POST 'https://app.memorylake.ai/openapi/memorylake/api/v3/workspaces/ws-fe314186ccd18cde04d6af48a5afd79f/actors/actor_5e4d3c2b1a0f/facts/fact-11a0e057d09877c9c492633fd60424fc/forget' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### Response

Returns an empty `data` object on success.

<ResponseExample>
```json Success (200)
{
  "success": true,
  "data": {}
}
```
</ResponseExample>
