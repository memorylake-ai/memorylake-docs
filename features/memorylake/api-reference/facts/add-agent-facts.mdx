---
title: "Add Agent Facts"
description: "Add one or more facts to an agent, stored exactly as written"
---

```
POST /openapi/memorylake/api/v3/workspaces/{workspaceId}/agents/{agentId}/facts
```

Adds one or more facts to an agent in a workspace. Each string you send is stored exactly as written, as a new fact of its own — nothing is extracted, merged, or rewritten. Use this when you already know a fact and want it in memory directly; otherwise facts are extracted from conversations automatically.

The response returns each created fact's `id` and text, in the order you sent them. To read a fact's metadata and timestamps, call [Get Agent Fact](/features/memorylake/api-reference/facts/get-agent-fact). In the fact's [change history](/features/memorylake/api-reference/facts/get-agent-fact-trace), a fact added this way starts with an `ADD` change whose `source_kind` is `MANUAL`.

<Note>
**Permission required:** `workspace_agent:fact_modify`
</Note>

### Path Parameters

<ParamField path="workspaceId" type="string" required>
Workspace ID
</ParamField>

<ParamField path="agentId" type="string" required>
Agent ID
</ParamField>

### Request Body

<ParamField body="facts" type="string[]" required>
Fact texts to add, one fact per entry. The list must not be empty and no entry may be blank; otherwise the request is rejected with `400`.
</ParamField>

<RequestExample>
```bash cURL
curl -X POST 'https://app.memorylake.ai/openapi/memorylake/api/v3/workspaces/ws-fe314186ccd18cde04d6af48a5afd79f/agents/agent-f8bf71ab17ed8eccad8c0e8ae708273f/facts' \
  -H 'Authorization: Bearer sk_xxxxxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "facts": [
      "Escalates billing disputes to the finance team.",
      "Reports times in UTC."
    ]
  }'
```
</RequestExample>
