---
title: "Forget Agent Fact"
description: "Mark an agent fact as forgotten without deleting it"
---

```
POST /openapi/memorylake/api/v3/workspaces/{workspaceId}/agents/{agentId}/facts/{factId}/forget
```

Marks an agent fact as forgotten (expired) without permanently deleting it. The fact remains available for audit purposes but is excluded from future retrievals and searches. To forget multiple agent facts at once, use [Batch Forget Agent Facts](/features/memorylake/api-reference/facts/batch-forget-agent-facts).

<Note>
**Permission required:** `workspace_agent:fact_delete`
</Note>

### Path Parameters

<ParamField path="workspaceId" type="string" required>
Workspace ID
</ParamField>

<ParamField path="agentId" type="string" required>
Agent ID
</ParamField>

<ParamField path="factId" type="string" required>
Fact ID to forget
</ParamField>

<RequestExample>
```bash cURL
curl -X POST 'https://app.memorylake.ai/openapi/memorylake/api/v3/workspaces/ws-fe314186ccd18cde04d6af48a5afd79f/agents/agent-f8bf71ab17ed8eccad8c0e8ae708273f/facts/fact-11a0e057d09877c9c492633fd60424fc/forget' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### Response

Returns an empty `data` object on success.

<ResponseExample>
```json Success (200)
{
  "success": true,
  "data": {}
}
```
</ResponseExample>
