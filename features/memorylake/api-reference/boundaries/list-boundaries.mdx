---
title: "List Boundaries"
description: "Returns a paginated list of the boundaries in a workspace"
---

```
GET /openapi/memorylake/api/v3/boundaries
```

Returns the boundaries in a workspace, newest first.

<Note>
**Permission required:** `boundary:read` — rows you cannot open are left out of the list rather than the list being refused
</Note>

### Query Parameters

<ParamField query="workspace_id" type="string" required>
Workspace ID
</ParamField>

<ParamField query="page_size" type="integer" default="20">
Number of boundaries per page, from 1 to 100.
</ParamField>

<ParamField query="continuation_token" type="string">
Token returned by the previous call. Omit on the first request.
</ParamField>

<ParamField query="name_fuzzy" type="string">
Fuzzy search by boundary name.
</ParamField>

<RequestExample>
```bash First page
curl -X GET 'https://app.memorylake.ai/openapi/memorylake/api/v3/boundaries?workspace_id=ws-8001856949ad4f6a5b6226f415ffa877&page_size=20' \
  -H 'Authorization: Bearer sk_xxxxxx'
```

```bash Search by name
curl -X GET 'https://app.memorylake.ai/openapi/memorylake/api/v3/boundaries?workspace_id=ws-8001856949ad4f6a5b6226f415ffa877&name_fuzzy=alice' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### Response

<ResponseField name="data" type="object">
<Expandable title="Paginated boundary list">
  <ResponseField name="items" type="array">
  Array of boundary objects
  <Expandable title="Boundary object">
    <ResponseField name="id" type="string">Boundary ID</ResponseField>
    <ResponseField name="custom_id" type="string">Your own identifier for the boundary, if you set one</ResponseField>
    <ResponseField name="workspace_id" type="string">Workspace the boundary belongs to</ResponseField>
    <ResponseField name="name" type="string">Boundary name</ResponseField>
    <ResponseField name="project_ids" type="string[]">Projects in scope. Absent when the scope is not narrowed to particular projects.</ResponseField>
    <ResponseField name="human_actor_id" type="string">Actor in scope. Absent when none is set.</ResponseField>
    <ResponseField name="agent_id" type="string">Agent whose memories are in scope. Absent when none is set.</ResponseField>
    <ResponseField name="created_at" type="string">Creation timestamp</ResponseField>
    <ResponseField name="updated_at" type="string">Last update timestamp</ResponseField>
  </Expandable>
  </ResponseField>
  <ResponseField name="continuation_token" type="string">Token for the next page. Absent or `null` when this is the last page.</ResponseField>
</Expandable>
</ResponseField>
