---
title: "Get Access Group"
description: "Returns one access group"
---

```
GET /openapi/memorylake/admin/v1/access-groups/{group_id}
```

Returns one access group. The `ETag` header covers the group's permission list — send it in If-Match to make [Set Access Group Permissions](/features/memorylake/api-reference/access-control/set-access-group-permissions) conditional.

<Note>
**Permission required:** `access_group:view`
</Note>

### Path Parameters

<ParamField path="group_id" type="string" required>
Identifier
</ParamField>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.ai/openapi/memorylake/admin/v1/access-groups/7013fb5c15cfb29411f040967354b8a3' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### Errors

Errors answer with `success: false`, a `message` and an `error_code`. See [Error Codes](/features/memorylake/api-reference/errors) for every code.

| Status | Meaning |
| --- | --- |
| `401` | The API key is missing, invalid, disabled or expired |
| `403` | The key is not allowed to do this |
| `404` | The resource does not exist |
| `422` | The body or a parameter failed validation |
| `429` | Too many requests. Wait for the time in `Retry-After` |
| `500` | Server-side error |
