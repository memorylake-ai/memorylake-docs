---
title: "Update Access Group"
description: "Renames an access group or changes its description"
---

```
PATCH /openapi/memorylake/admin/v1/access-groups/{group_id}
```

Renames an access group or changes its description. Only the fields you send change; null is rejected. The base role or base group cannot be changed. The response is the group as [Get Access Group](/features/memorylake/api-reference/access-control/get-access-group) returns it, so view is required as well.

<Note>
**Permission required:** `access_group:manage` and `access_group:view`
</Note>

### Path Parameters

<ParamField path="group_id" type="string" required>
Identifier
</ParamField>

### Headers

<ParamField header="Idempotency-Key" type="string">
Optional. Retrying with the same value replays the first result.
</ParamField>

### Request Body

<ParamField body="description" type="string">
New description; "" clears it
</ParamField>

<ParamField body="name" type="string">
New display name
</ParamField>

<RequestExample>
```bash cURL
curl -X PATCH 'https://app.memorylake.ai/openapi/memorylake/admin/v1/access-groups/7013fb5c15cfb29411f040967354b8a3' \
  -H 'Authorization: Bearer sk_xxxxxx' \
  -H 'Idempotency-Key: 7c1d2e3f-0a9b-4c8d-b7e6-f5a4d3c2b1a0' \
  -H 'Content-Type: application/json' \
  -d '{
    "description": "Example description",
    "name": "Example name"
  }'
```
</RequestExample>
