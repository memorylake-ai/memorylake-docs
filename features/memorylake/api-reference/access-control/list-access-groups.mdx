---
title: "List Access Groups"
description: "Lists the access groups of your team"
---

```
GET /openapi/memorylake/admin/v1/access-groups
```

Lists the access groups of your team. An access group gives its members extra permissions and access to extra instances; it never takes access away.

<Note>
**Permission required:** `access_group:view`
</Note>

### Query Parameters

<ParamField query="page_size" type="integer">
Page size, 1–100 (default 20)
</ParamField>

<ParamField query="continuation_token" type="string">
Token from the previous page
</ParamField>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.ai/openapi/memorylake/admin/v1/access-groups' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>
