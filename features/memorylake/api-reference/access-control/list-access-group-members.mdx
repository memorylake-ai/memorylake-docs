---
title: "List Access Group Members"
description: "Lists the members of an access group"
---

```
GET /openapi/memorylake/admin/v1/access-groups/{group_id}/members
```

Lists the members of an access group.

<Note>
**Permission required:** `access_group:view`
</Note>

### Path Parameters

<ParamField path="group_id" type="string" required>
Identifier
</ParamField>

### Query Parameters

<ParamField query="page_size" type="integer">
Page size, 1–100 (default 20)
</ParamField>

<ParamField query="continuation_token" type="string">
Token from the previous page
</ParamField>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.ai/openapi/memorylake/admin/v1/access-groups/7013fb5c15cfb29411f040967354b8a3/members' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### Response

  List of items in the current page
