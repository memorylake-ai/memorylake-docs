---
title: "Set Access Group Access Scope"
description: "Replaces, per listed resource type, the instances the group gives its members access to"
---

```
PUT /openapi/memorylake/admin/v1/access-groups/{group_id}/access-scope
```

Replaces, per listed resource type, the instances the group gives its members access to. A group only adds access: mode all removes the type's instances from the group and limits nobody. Project instances need their workspace_id. The response is the scope as [Get Access Group Access Scope](/features/memorylake/api-reference/access-control/get-access-group-access-scope) returns it, so view is required as well.

The response carries an `ETag` header (the same value a GET of this resource returns). Send it back in `If-Match` to make the write conditional: when the resource has changed in the meantime the write is refused with 412 and nothing is changed. The check narrows, but does not fully close, the window for a concurrent overwrite — two writers that pass it at the same instant can both write.

<Note>
**Permission required:** `access_group:manage` and `access_group:view`

- Changes that give someone an admin role, or that reduce what an admin can reach, also require the team owner or an admin.
</Note>

### Path Parameters

<ParamField path="group_id" type="string" required>
Identifier
</ParamField>

### Headers

<ParamField header="If-Match" type="string">
Optional. The ETag from a previous read of this resource. The write is refused with 412 when the resource has changed since; omit it to overwrite unconditionally.
</ParamField>

### Request Body

<ParamField body="reason" type="string" required>
Why the change is made; recorded in the audit log
</ParamField>

<ParamField body="scopes" type="array" required>
Each listed resource type's instance list is replaced by the given one; mode all removes the type's instances (a group never limits anyone). Types not listed keep their current list.
<Expandable title="Access Scope Entry object">
  <ParamField body="scopes[].mode" type="string" required>all = every instance; instances = only the listed ones</ParamField>
  <ParamField body="scopes[].resource_type" type="string" required>Resource type, e.g. memorylake:project</ParamField>
  <ParamField body="scopes[].instances" type="array">
  Required when mode is instances
  <Expandable title="Access Scope Instance object">
    <ParamField body="scopes[].instances[].id" type="string" required>Instance id</ParamField>
    <ParamField body="scopes[].instances[].actions" type="array">Omit for every action the member's role allows</ParamField>
    <ParamField body="scopes[].instances[].via_permission_level" type="boolean">Echo of a read-only row. Instances marked true are skipped on write — permission levels are set on the resource, not through scope.</ParamField>
    <ParamField body="scopes[].instances[].workspace_id" type="string">Parent workspace — required for project instances</ParamField>
  </Expandable>
  </ParamField>
</Expandable>
</ParamField>
