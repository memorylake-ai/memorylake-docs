---
title: "Delete Access Group"
description: "Deletes an access group; its members lose what it gave them"
---

```
DELETE /openapi/memorylake/admin/v1/access-groups/{group_id}
```

Deletes an access group; its members lose what it gave them. Refused with 409 while other access groups are based on it.

<Note>
**Permission required:** `access_group:manage`

- Changes that give someone an admin role, or that reduce what an admin can reach, also require the team owner or an admin.
</Note>

### Path Parameters

<ParamField path="group_id" type="string" required>
Identifier
</ParamField>
