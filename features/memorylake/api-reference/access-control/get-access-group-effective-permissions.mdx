---

```
GET /openapi/memorylake/admin/v1/access-groups/{group_id}/effective-permissions
```

Returns everything the group grants, each permission with where it comes from (the base role or base group, or the group's own list), plus the instances it gives access to.

<Note>
**Permission required:** `access_group:view`
</Note>

### Path Parameters

<ParamField path="group_id" type="string" required>
Identifier
</ParamField>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.ai/openapi/memorylake/admin/v1/access-groups/7013fb5c15cfb29411f040967354b8a3/effective-permissions' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>
