---
title: "Create Access Group"
description: "Creates an access group"
---

```
POST /openapi/memorylake/admin/v1/access-groups
```

Creates an access group. Its permissions come from an optional base — a role (base_role_key) or another access group (base_access_group_id), fixed at creation — plus its own permission list. Only an owner or admin may create a group based on tenant_admin. A team has at most 200 access groups.

<Note>
**Permission required:** `access_group:manage`

- Changes that give someone an admin role, or that reduce what an admin can reach, also require the team owner or an admin.
</Note>

### Headers

<ParamField header="Idempotency-Key" type="string">
Optional. Retrying with the same value replays the first result instead of creating a second group.
</ParamField>

### Request Body

<ParamField body="name" type="string" required>
Display name
</ParamField>

<ParamField body="base_access_group_id" type="string">
Optional, exclusive with base_role_key. The group grants everything this access group grants.
</ParamField>

<ParamField body="base_role_key" type="string">
Optional. The group grants everything this role grants. Granting tenant_admin needs an owner or admin. One of: `tenant_member`, `tenant_admin`.
</ParamField>

<ParamField body="description" type="string">
Optional description
</ParamField>

<ParamField body="permissions" type="array">
Optional permissions on top of the base
<Expandable title="Access Group Permission object">
  <ParamField body="permissions[].action" type="string" required>Action</ParamField>
  <ParamField body="permissions[].resource_type" type="string" required>Resource type (see GET /permission-catalog?grantable_to=access_group)</ParamField>
</Expandable>
</ParamField>

<RequestExample>
```bash cURL

  -H 'Authorization: Bearer sk_xxxxxx' \

  -d '{
    "name": "Example name",
    "base_access_group_id": "654c7f7dfc968117cbb5a2e1e31a838e",
    "base_role_key": "tenant_member",
    "description": "Example description",
    "permissions": [
      {
        "action": "example",
        "resource_type": "example"
      }
    ]
  }'
```
</RequestExample>
