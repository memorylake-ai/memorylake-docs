---
title: "Remove Access Group Member"
description: "Removes one member from an access group"
---

```
DELETE /openapi/memorylake/admin/v1/access-groups/{group_id}/members/{principal_id}
```

Removes one member from an access group. A principal that is not in the group is a 404.

<Note>
**Permission required:** `access_group:manage`

- Changes that give someone an admin role, or that reduce what an admin can reach, also require the team owner or an admin.
</Note>

### Path Parameters

<ParamField path="group_id" type="string" required>
Identifier
</ParamField>

<ParamField path="principal_id" type="string" required>
The member to remove
</ParamField>
