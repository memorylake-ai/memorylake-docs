---
title: "List Open Data Collections"
description: "List the Open Data collections an agent can search, with the identifiers to pass in open_datasets"
---

```
GET /openapi/memorylake/api/v1/industry-opendata
```

Lists the Open Data collections that MemoryLake curates. To have an agent search a collection alongside the web, pass its `id` in `web_search.open_datasets` when you [send the agent a message](/features/memorylake/api-reference/a2a/overview#turn-on-capabilities-per-message).

The list is the same for every caller. Names and descriptions are in English, and entries come back in no particular order.

<Tip>
Read the identifiers from this endpoint instead of hard-coding them. Collections can be added over time.
</Tip>

<Note>
**Permission required:** none. The list is the same for every caller.
</Note>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.ai/openapi/memorylake/api/v1/industry-opendata' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### Response

<ResponseField name="data" type="array">
Array of Open Data collections
<Expandable title="Collection object">
  <ResponseField name="id" type="string">Collection identifier, for example `research/academic`. Pass it in `open_datasets`.</ResponseField>
  <ResponseField name="name" type="string">Display name</ResponseField>
  <ResponseField name="description" type="string">What the collection contains</ResponseField>
</Expandable>
</ResponseField>
