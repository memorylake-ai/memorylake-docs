---
title: "List Audit Logs"
description: "Lists the team's audit events, newest first: management changes (category management) and events the platform recorded on its own (category system)"
---

```
GET /openapi/memorylake/admin/v1/audit-logs
```

Lists the team's audit events, newest first: management changes (category management) and events the platform recorded on its own (category system). Changes made through this API with an API key name the key (actor.type api_key). With log:read_all the list covers the team; a caller holding only log:read_self sees the events they performed, and filtering by another member's actor_id is refused. The window defaults to the last 7 days and may span at most 92 days. Unlike other lists this one returns no total — page with continuation_token until it is absent. Rate limit: 20 requests per minute per key by default, counted separately from all other operations. When paging through many records, use the largest page_size (100).

<Note>
**Permission required:** `log:read_all` (whole team) or `log:read_self` (your own only)

- When you filter by another member's `actor_id`: `log:read_all`
</Note>

### Query Parameters

<ParamField query="page_size" type="integer" default="20">
Number of items per page (1–100)
</ParamField>

<ParamField query="continuation_token" type="string">
Token from the previous page. Opaque — do not construct or parse it. Send the same filters with it.
</ParamField>

<ParamField query="category" type="string">
management: changes people and keys made to the team (members, roles, keys, billing settings). system: events the platform recorded on its own (subscription ended, low-balance alerts, …). Omit for both.
</ParamField>

<ParamField query="action" type="array">
Only these actions, e.g. member:change_role. Repeat the parameter for several.
</ParamField>

<ParamField query="actor_id" type="array">
Only events performed by these members (principal_id). Repeat the parameter for several. A caller limited to their own events may only pass their own id.
</ParamField>

<ParamField query="target_type" type="string">
Only events on this kind of target, e.g. principal, service_account.
</ParamField>

<ParamField query="target_id" type="string">
Only events on this target id.
</ParamField>

<ParamField query="result" type="string">
Only events with this outcome. One of: `succeeded`, `failed`, `partial`.
</ParamField>

<ParamField query="start_time" type="integer">
Earliest event time to include, Unix seconds (inclusive). Defaults to 7 days before end_time.
</ParamField>

<ParamField query="end_time" type="integer">
Latest event time, Unix seconds (exclusive). Defaults to now. The window may span at most 92 days.
</ParamField>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.ai/openapi/memorylake/admin/v1/audit-logs' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>
