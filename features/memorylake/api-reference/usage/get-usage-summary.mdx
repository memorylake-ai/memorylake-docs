---
title: "Get Usage Summary"
description: "Returns consumption for today, the trailing 7 days and the month to date"
---

```
GET /openapi/memorylake/admin/v1/usage/summary
```

Returns consumption for today, the trailing 7 days and the month to date. Same scope rule and same figures as [Get Usage](/features/memorylake/api-reference/usage/get-usage) (platform metering operations included): the team with usage:view_all, otherwise the caller's own usage.

<Note>
**Permission required:** `usage:view_all` (whole team) or `usage:view_self` (your own only)
</Note>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.ai/openapi/memorylake/admin/v1/usage/summary' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>
