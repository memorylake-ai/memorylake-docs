---
title: "Get Usage"
description: "Returns the current quota snapshot plus consumption over the requested period (at most 92 days)"
---

```
GET /openapi/memorylake/admin/v1/usage
```

Returns the current quota snapshot plus consumption over the requested period (at most 92 days). With usage:view_all the figures cover the whole team; a caller holding only usage:view_self receives their own usage (including their API keys), and `scope` says which. bucket_width=1d adds a per-day series; group_by=member adds a per-member breakdown and requires usage:view_all.

<Note>
**Permission required:** `usage:view_all` (whole team) or `usage:view_self` (your own only)

- When you pass `group_by=member`: `usage:view_all`
</Note>

### Query Parameters

<ParamField query="start_date" type="string">
First day to include, YYYY-MM-DD, in the timezone stated by period.timezone. Defaults to six days before end_date.
</ParamField>

<ParamField query="end_date" type="string">
Last day to include, YYYY-MM-DD, in the timezone stated by period.timezone. Defaults to today.
</ParamField>

<ParamField query="bucket_width" type="string">
Set to 1d to also receive buckets: a per-day time series over the period.
</ParamField>

<ParamField query="group_by" type="array">
Repeatable. by_model is always returned for the period; member adds by_member (requires usage:view_all). With bucket_width=1d, each bucket also carries the breakdowns listed here.
</ParamField>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.ai/openapi/memorylake/admin/v1/usage' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>
