---
title: "Delete Agent"
description: "Permanently delete an agent and all its versions"
---

```
DELETE /openapi/memorylake/api/v3/agents/{id}
```

<Warning>
This is a destructive operation. The agent and all its versions are permanently removed. Its workspace bindings are **not** removed: they remain in [List Workspace Agents](/features/memorylake/api-reference/agents/list-workspace-agents) with `status` set to `INACTIVE` — read-only, so memories the agent already recorded stay readable. To remove a binding, call [Unbind Agent](/features/memorylake/api-reference/agents/unbind-agent).
</Warning>

Permanently deletes an agent. This action cannot be undone.

<Note>
**Permission required:** `agent:delete`
</Note>

### Path Parameters

<ParamField path="id" type="string" required>
Agent identifier
</ParamField>

<RequestExample>
```bash cURL
curl -X DELETE 'https://app.memorylake.ai/openapi/memorylake/api/v3/agents/agt_r8k2m1n3' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### Response

Returns an empty `data` field on success.

<ResponseExample>
```json Success (200)
{
  "success": true,
  "data": {}
}
```
</ResponseExample>
