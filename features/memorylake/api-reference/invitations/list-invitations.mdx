title: "List Invitations"
description: "Lists the team's invitations, newest first, optionally filtered by state and by email address (repeat email= to check several addresses at once)"
---

```
GET /openapi/memorylake/admin/v1/invitations
```

Lists the team's invitations, newest first, optionally filtered by state and by email address (repeat email= to check several addresses at once).

<Note>
**Permission required:** `member:invite`
</Note>

### Query Parameters

<ParamField query="page_size" type="integer" default="20">
Number of items per page (1–100)
</ParamField>

<ParamField query="continuation_token" type="string">
Token from the previous page. Opaque — do not construct or parse it.
</ParamField>

<ParamField query="status" type="string">
Only return invitations in this state. One of: `pending`, `accepted`, `rejected`, `expired`, `revoked`.
</ParamField>

<ParamField query="email" type="array">
Only return invitations for these addresses (case-insensitive). Repeat the parameter for several.
</ParamField>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.ai/openapi/memorylake/admin/v1/invitations' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

    <ResponseField name="accepted_principal_id" type="string">principal_id of the member this invitation produced. Present only when accepted.</ResponseField>
