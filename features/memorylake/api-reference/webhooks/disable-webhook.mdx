---
title: "Disable Webhook"
description: "Stops sending"
---

```
POST /openapi/memorylake/admin/v1/webhooks/{webhook_id}/disable
```

Stops sending. Events that happen while it is off are recorded as skipped deliveries and can be resent for 15 days after it is enabled again.

<Note>
**Permission required:** `webhook:manage`
</Note>

### Path Parameters

<ParamField path="webhook_id" type="string" required>
Identifier of the webhook
</ParamField>

<RequestExample>
```bash cURL
curl -X POST 'https://app.memorylake.ai/openapi/memorylake/admin/v1/webhooks/16522a01eaa7b9feef48caafb0b487a5/disable' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### Response

<ResponseField name="data" type="object">
<Expandable title="Webhook object">
  <ResponseField name="all_events" type="boolean">true = every event type is sent, including types added in the future; events is then the selection kept for when this is switched off</ResponseField>
  <ResponseField name="created_at" type="integer">When the webhook was added, Unix seconds</ResponseField>
  <ResponseField name="description" type="string">Description; empty when none was given</ResponseField>
  <ResponseField name="events" type="array">Selected event types (see [List Event Types](/features/memorylake/api-reference/webhooks/list-webhook-event-types))</ResponseField>
  <ResponseField name="secret_last4" type="string">Last four characters of the current signing secret. The full secret is returned only by [Add Webhook](/features/memorylake/api-reference/webhooks/create-webhook) and [Rotate Signing Secret](/features/memorylake/api-reference/webhooks/rotate-webhook-secret).</ResponseField>
  <ResponseField name="status" type="string">auto_disabled = turned off after every delivery failed for 3 days; enable it after fixing the endpoint. One of: `enabled`, `disabled`, `auto_disabled`.</ResponseField>
  <ResponseField name="url" type="string">Endpoint URL events are sent to</ResponseField>
  <ResponseField name="webhook_id" type="string">Identifier of the webhook</ResponseField>
  <ResponseField name="created_by_member_id" type="string">Member who added the webhook</ResponseField>
  <ResponseField name="last_delivery_at" type="integer">Time of the latest attempt, Unix seconds; absent if nothing was sent yet</ResponseField>
  <ResponseField name="last_delivery_succeeded" type="boolean">Whether the latest delivery succeeded</ResponseField>
  <ResponseField name="previous_secret_expires_at" type="integer">Until when the previous secret still signs requests after a rotation, Unix seconds; absent outside that window</ResponseField>
  <ResponseField name="secret_rotated_at" type="integer">When the signing secret was last rotated, Unix seconds; absent if never</ResponseField>
</Expandable>
</ResponseField>

### Errors

Errors answer with `success: false`, a `message` and an `error_code`. See [Error Codes](/features/memorylake/api-reference/errors) for every code.

| Status | Meaning |
| --- | --- |
| `401` | The API key is missing, invalid, disabled or expired |
| `403` | The key is not allowed to do this |
| `404` | The resource does not exist |
| `422` | The body or a parameter failed validation |
| `429` | Too many requests. Wait for the time in `Retry-After` |
| `500` | Server-side error |
