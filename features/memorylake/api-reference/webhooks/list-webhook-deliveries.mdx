---
title: "List Deliveries"
description: "Lists a webhook's deliveries of the last 15 days, newest event first"
---

```
GET /openapi/memorylake/admin/v1/webhooks/{webhook_id}/deliveries
```

Lists a webhook's deliveries of the last 15 days, newest event first. One delivery is one event sent to this webhook; automatic retries and resends are further attempts of the same delivery.

<Note>
**Permission required:** `webhook:manage`
</Note>

### Path Parameters

<ParamField path="webhook_id" type="string" required>
Identifier of the webhook
</ParamField>

### Query Parameters

<ParamField query="result" type="string">
Only deliveries with this result; failed includes those still retrying. One of: `succeeded`, `failed`, `skipped`.
</ParamField>

<ParamField query="event_type" type="string">
Only this event type
</ParamField>

<ParamField query="page_size" type="integer" default="20">
Items per page (1–100)
</ParamField>

<ParamField query="continuation_token" type="string">
Token from the previous page
</ParamField>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.ai/openapi/memorylake/admin/v1/webhooks/16522a01eaa7b9feef48caafb0b487a5/deliveries' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>
