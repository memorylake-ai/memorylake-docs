---
title: "Delete Actor"
description: "Permanently delete an actor"
---

```
DELETE /openapi/memorylake/api/v3/actors/{id}
```

Permanently deletes an actor. Its workspace bindings are **not** removed: they remain in [List Workspace Actors](/features/memorylake/api-reference/actors/list-workspace-actors) with `status` set to `INACTIVE`. An inactive binding is read-only — memories the actor already recorded in that workspace stay readable, but it no longer takes part in writes. To remove a binding, call [Unbind Actor](/features/memorylake/api-reference/actors/unbind-actor), which also works after the actor is deleted.

<Note>
**Permission required:** `actor:delete`
</Note>

<Warning>
This action is irreversible. Memories and conversation history associated with the actor are not deleted, but the actor can no longer be referenced in new conversations.
</Warning>

### Path Parameters

<ParamField path="id" type="string" required>
Actor ID
</ParamField>

<RequestExample>
```bash cURL
curl -X DELETE 'https://app.memorylake.ai/openapi/memorylake/api/v3/actors/act-a1b2c3d4e5f6' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>
