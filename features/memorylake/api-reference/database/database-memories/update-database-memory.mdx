---
title: "Update Database Memory"
description: "Rename a database memory, change its instruction, or bind a different analysis model"
noindex: true
---

```
PATCH /openapi/memorylake/api/v3/workspaces/{workspaceId}/projects/{projectId}/memories/databases/{databaseId}
```

Partially updates a database memory. Fields you leave out stay unchanged. You can rename the memory, change or clear its instruction, and bind, replace or remove its analysis model. The datasource a memory reads cannot be changed; create another memory for a different datasource.

The request is refused if the analysis model is not in this workspace or is built on a different datasource than the memory.

<Note>
**Permission required:** `project:dbset_modify` on the project
</Note>

### Path Parameters

<ParamField path="workspaceId" type="string" required>
ID of the workspace the project belongs to
</ParamField>

<ParamField path="projectId" type="string" required>
Project ID
</ParamField>

<ParamField path="databaseId" type="string" required>
Database memory ID
</ParamField>

### Request Body

<ParamField body="name" type="string">
New display name. An empty value is ignored, so the name cannot be cleared.
</ParamField>

<ParamField body="instruction" type="string">
New guidance for how questions against this database should be answered: what the data means, which tables matter, house conventions. Send an empty string to clear it. [Generate Database Memory Instruction](/features/memorylake/api-reference/database/database-memories/generate-database-memory-instruction) can draft one for you.
</ParamField>

<ParamField body="analysis_model_id" type="string">
ID of the analysis model this memory should draw its knowledge from. It must be built on the same datasource as the memory, and you need `analysis_model:read` on it. Send an empty string to remove the current binding.
</ParamField>

<RequestExample>
```bash Change the instruction
curl -X PATCH 'https://app.memorylake.ai/openapi/memorylake/api/v3/workspaces/ws-8001856949ad4f6a5b6226f415ffa877/projects/proj-b93e8d95a8705bcc4ec42a65ba4cc7f8/memories/databases/doc-2e6a9c4f8b1d4a7e9c3b5d8f0a2c4e6b' \
  -H 'Authorization: Bearer sk_xxxxxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "instruction": "All amounts are in US dollars. Answer revenue questions from sales.orders.total_amount, treat created_at as UTC, and join customers on customer_id."
  }'
```

```bash Remove the analysis model
curl -X PATCH 'https://app.memorylake.ai/openapi/memorylake/api/v3/workspaces/ws-8001856949ad4f6a5b6226f415ffa877/projects/proj-b93e8d95a8705bcc4ec42a65ba4cc7f8/memories/databases/doc-2e6a9c4f8b1d4a7e9c3b5d8f0a2c4e6b' \
  -H 'Authorization: Bearer sk_xxxxxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "analysis_model_id": ""
  }'
```
</RequestExample>

### Response

Returns the updated database memory.

  <ResponseField name="error" type="object">
  Details of the failure. Present only when `status` is `error`, and only when a cause was reported.
  <Expandable title="Error details">
    <ResponseField name="code" type="string">Error code</ResponseField>
    <ResponseField name="msg" type="string">Error message</ResponseField>

  </ResponseField>
  <ResponseField name="project_id" type="string">ID of the project the memory belongs to</ResponseField>
  <ResponseField name="db_datasource_id" type="string">Datasource this memory reads</ResponseField>

</Expandable>
</ResponseField>
