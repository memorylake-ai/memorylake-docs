---
title: "Get Database Memory"
description: "Retrieve a database memory, including its instruction and processing status"
noindex: true
---

```
GET /openapi/memorylake/api/v3/workspaces/{workspaceId}/projects/{projectId}/memories/databases/{databaseId}
```

Retrieves a database memory by its ID. Use it to read the memory's instruction, which list results leave out, or to poll its `status` after you create or reload it.

<Note>
**Permission required:** `project:dbset_read` on the project
</Note>

### Path Parameters

<ParamField path="workspaceId" type="string" required>
ID of the workspace the project belongs to
</ParamField>

<ParamField path="projectId" type="string" required>
Project ID
</ParamField>

<ParamField path="databaseId" type="string" required>
Database memory ID
</ParamField>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.ai/openapi/memorylake/api/v3/workspaces/ws-8001856949ad4f6a5b6226f415ffa877/projects/proj-b93e8d95a8705bcc4ec42a65ba4cc7f8/memories/databases/doc-2e6a9c4f8b1d4a7e9c3b5d8f0a2c4e6b' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### Response

<ResponseField name="data" type="object">
<Expandable title="Database memory object">
  <ResponseField name="id" type="string">Database memory identifier. Treat it as an opaque string.</ResponseField>
  <ResponseField name="name" type="string">Display name</ResponseField>
  <ResponseField name="instruction" type="string">Guidance for how questions against this database should be answered: what the data means, which tables matter, house conventions. Empty when none is set.</ResponseField>
  <ResponseField name="status" type="string">Processing status: `pending`, `running`, `okay`, or `error`. The memory is ready to use once it is `okay`.</ResponseField>
  <ResponseField name="error" type="object">
  Details of the failure. Present only when `status` is `error`, and only when a cause was reported.
  <Expandable title="Error details">
    <ResponseField name="code" type="string">Error code</ResponseField>
    <ResponseField name="msg" type="string">Error message</ResponseField>
  </Expandable>
  </ResponseField>
  <ResponseField name="project_id" type="string">ID of the project the memory belongs to</ResponseField>
  <ResponseField name="db_datasource_id" type="string">Datasource this memory reads</ResponseField>
  <ResponseField name="analysis_model_id" type="string">Analysis model this memory draws its knowledge from. Omitted when none is bound.</ResponseField>
  <ResponseField name="created_at" type="string">Creation timestamp</ResponseField>
</Expandable>
</ResponseField>
