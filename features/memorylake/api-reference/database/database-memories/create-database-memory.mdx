---
title: "Create Database Memory"
description: "Add a datasource to a project as a memory source"
noindex: true
---

```
POST /openapi/memorylake/api/v3/workspaces/{workspaceId}/projects/{projectId}/memories/databases
```

Adds a datasource to a project as a memory source, so that questions in the project can be answered from that database. You can also bind an analysis model built on the same datasource and give an instruction for how questions should be answered.

The memory is processed asynchronously. It starts with `status` `pending`; poll [Get Database Memory](/features/memorylake/api-reference/database/database-memories/get-database-memory) until it is `okay`, or `error` if processing failed.

The request is refused if the datasource is not in the workspace this project belongs to, or if the analysis model is built on a different datasource.

<Note>
**Permission required:** `project:dbset_add` on the project and `db_datasource:read` on the datasource
</Note>

### Path Parameters

<ParamField path="workspaceId" type="string" required>
ID of the workspace the project belongs to
</ParamField>

<ParamField path="projectId" type="string" required>
Project ID
</ParamField>

### Request Body

<ParamField body="name" type="string" required>
Display name
</ParamField>

<ParamField body="db_datasource_id" type="string" required>
ID of the datasource this memory reads. It must belong to the workspace this project is in, and you need `db_datasource:read` on it.
</ParamField>

<ParamField body="analysis_model_id" type="string">
ID of an analysis model for this memory to draw its knowledge from. It must be built on the same datasource, and you need `analysis_model:read` on it. Omit it to create the memory without one.
</ParamField>

<ParamField body="instruction" type="string">
Guidance for how questions against this database should be answered: what the data means, which tables matter, house conventions. Omit it to start without one. You can change it later with [Update Database Memory](/features/memorylake/api-reference/database/database-memories/update-database-memory), or have one drafted with [Generate Database Memory Instruction](/features/memorylake/api-reference/database/database-memories/generate-database-memory-instruction).
</ParamField>

<RequestExample>
```bash cURL
curl -X POST 'https://app.memorylake.ai/openapi/memorylake/api/v3/workspaces/ws-8001856949ad4f6a5b6226f415ffa877/projects/proj-b93e8d95a8705bcc4ec42a65ba4cc7f8/memories/databases' \
  -H 'Authorization: Bearer sk_xxxxxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "name": "Sales database",
    "db_datasource_id": "dbds-4b8e2f6a1c9d4e7b8a3f5c2d6e9b1a7c",
    "analysis_model_id": "am-9d3f7b1e5a2c4d8f6b0e3a7c9d1f5b2e",
    "instruction": "All amounts are in US dollars. Answer revenue questions from sales.orders.total_amount and treat created_at as UTC."
  }'
```
</RequestExample>

### Response

Returns the new database memory.

<ResponseField name="data" type="object">
<Expandable title="Database memory object">
  <ResponseField name="id" type="string">Database memory identifier. Treat it as an opaque string.</ResponseField>
  <ResponseField name="name" type="string">Display name</ResponseField>
  <ResponseField name="instruction" type="string">The instruction you sent. Omitted if you did not send one.</ResponseField>
  <ResponseField name="status" type="string">Processing status. A new memory starts as `pending`.</ResponseField>
  <ResponseField name="project_id" type="string">ID of the project the memory belongs to</ResponseField>
  <ResponseField name="db_datasource_id" type="string">Datasource this memory reads</ResponseField>
  <ResponseField name="analysis_model_id" type="string">Analysis model this memory draws its knowledge from. Omitted when none is bound.</ResponseField>
</Expandable>
</ResponseField>
