---
title: "Create Database Connection"
description: "Save how to reach a database and the credentials for it"
noindex: true
---

```
POST /openapi/memorylake/api/v3/db-connections
```

Saves how to reach a database and the credentials to read it. A connection belongs to your team and can serve datasources in any workspace.

The password is write-only: no endpoint ever returns it. To check the credentials first, call [Test Database Connectivity](/features/memorylake/api-reference/database/connections/test-database-connectivity).

<Note>
**Permission required:** `dbconn:add`
</Note>

### Request Body

<ParamField body="name" type="string" required>
Display name
</ParamField>

<ParamField body="host" type="string" required>
Server host name or address
</ParamField>

<ParamField body="port" type="integer" default="5432">
Server port, from 1 to 65535
</ParamField>

<ParamField body="database" type="string" required>
Name of the database to read
</ParamField>

<ParamField body="username" type="string" required>
User name to authenticate with
</ParamField>

<ParamField body="password" type="string" required>
Password to authenticate with. It is never returned by any endpoint.
</ParamField>

<ParamField body="description" type="string">
Free-form description
</ParamField>

<ParamField body="custom_id" type="string">
Your own identifier for this connection, up to 255 characters. Must be unique within your tenant, cannot be changed once set, and must not start with `_sys_`. Pass `by_custom_id=true` on [Get Database Connection](/features/memorylake/api-reference/database/connections/get-database-connection) to look the connection up by it. See [Your own identifiers](/features/memorylake/api-reference/overview#your-own-identifiers).
</ParamField>

<RequestExample>
```bash cURL
curl -X POST 'https://app.memorylake.ai/openapi/memorylake/api/v3/db-connections' \
  -H 'Authorization: Bearer sk_xxxxxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "name": "Sales warehouse",
    "description": "Read-only replica of the sales database",
    "host": "pg.internal.example.com",
    "port": 5432,
    "database": "sales",
    "username": "analytics_ro",
    "password": "your-database-password",
    "custom_id": "sales-warehouse"
  }'
```
</RequestExample>
