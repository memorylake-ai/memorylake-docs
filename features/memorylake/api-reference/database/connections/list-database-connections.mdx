---
title: "List Database Connections"
description: "Returns a paginated list of the database connections you can open"
noindex: true
---

```
GET /openapi/memorylake/api/v3/db-connections
```

Returns the database connections in your team that you can open. Filter by name and page through the results with continuation tokens.

<Note>
**Permission required:** `dbconn:read` — connections you cannot open are left out of the list rather than the list being refused
</Note>

### Query Parameters

<ParamField query="name_fuzzy" type="string">
Only return connections whose name contains this text (case-insensitive)
</ParamField>

<ParamField query="page_size" type="integer" default="20">
Number of connections to return per page, from 1 to 100
</ParamField>

<ParamField query="continuation_token" type="string">
Token from a previous response to fetch the next page. Omit it for the first page.
</ParamField>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.ai/openapi/memorylake/api/v3/db-connections?page_size=20' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### Response

<ResponseField name="data" type="object">
<Expandable title="Paginated connection list">
  <ResponseField name="items" type="array">
  Array of connection objects
  <Expandable title="Connection object">
    <ResponseField name="id" type="string">Database connection identifier. Treat it as an opaque string.</ResponseField>
    <ResponseField name="name" type="string">Display name</ResponseField>
    <ResponseField name="description" type="string">Free-form description</ResponseField>
    <ResponseField name="host" type="string">Server host name or address</ResponseField>
    <ResponseField name="port" type="integer">Server port</ResponseField>
    <ResponseField name="username" type="string">User name the connection authenticates with</ResponseField>
    <ResponseField name="database" type="string">Name of the database to read</ResponseField>
    <ResponseField name="custom_id" type="string">Your own identifier for this connection, if you set one</ResponseField>
    <ResponseField name="datasource_count" type="integer">Number of datasources that currently read through this connection</ResponseField>
    <ResponseField name="created_at" type="string">Creation timestamp</ResponseField>
    <ResponseField name="updated_at" type="string">Last update timestamp</ResponseField>
  </Expandable>
  </ResponseField>
  <ResponseField name="continuation_token" type="string">
  Token to retrieve the next page. Omitted on the last page.
  </ResponseField>
  <ResponseField name="total" type="integer">
  Total number of matching connections across all pages. Omitted when the list is filtered by your permissions; page through with `continuation_token` instead.
  </ResponseField>
</Expandable>
</ResponseField>
