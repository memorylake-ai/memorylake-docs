---
title: "Disable or Restore Knowledge Entry"
description: "Take a knowledge entry out of use without deleting it, or put it back"
noindex: true
---

```
POST /openapi/memorylake/api/v3/workspaces/{workspaceId}/analysis-models/{modelId}/entries/{entryId}/disable
```

Takes a knowledge entry out of use without deleting it, or puts it back. A disabled entry stays in the model with its content, but it is excluded from answering and left out of [keyword searches](/features/memorylake/api-reference/database/analysis-models/list-knowledge-entries). Its `updated_at` changes either way.

Some kinds cannot be disabled, such as general knowledge.

<Note>
**Permission required:** `analysis_model:modify`
</Note>

### Path Parameters

<ParamField path="workspaceId" type="string" required>
Workspace ID
</ParamField>

<ParamField path="modelId" type="string" required>
Analysis model ID
</ParamField>

<ParamField path="entryId" type="string" required>
Knowledge entry ID
</ParamField>

### Request Body

<ParamField body="disabled" type="boolean" required>
`true` to exclude the entry from answering, `false` to put it back into use
</ParamField>

<ParamField body="entity_type" type="string">
Kind of the entry, as it was created, such as `few_shot`. Some kinds cannot be found from the ID alone.
</ParamField>

<RequestExample>
```bash Disable
curl -X POST 'https://app.memorylake.ai/openapi/memorylake/api/v3/workspaces/ws-8001856949ad4f6a5b6226f415ffa877/analysis-models/am-9d3f7b1e5a2c4d8f6b0e3a7c9d1f5b2e/entries/5d2e7b9cb31d11f1a7c35e9b2d4f6a81/disable' \
  -H 'Authorization: Bearer sk_xxxxxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "disabled": true,
    "entity_type": "few_shot"
  }'
```

```bash Restore
curl -X POST 'https://app.memorylake.ai/openapi/memorylake/api/v3/workspaces/ws-8001856949ad4f6a5b6226f415ffa877/analysis-models/am-9d3f7b1e5a2c4d8f6b0e3a7c9d1f5b2e/entries/5d2e7b9cb31d11f1a7c35e9b2d4f6a81/disable' \
  -H 'Authorization: Bearer sk_xxxxxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "disabled": false,
    "entity_type": "few_shot"
  }'
```
</RequestExample>
