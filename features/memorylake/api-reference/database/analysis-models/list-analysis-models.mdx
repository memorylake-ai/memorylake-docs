---
title: "List Analysis Models"
description: "Returns a paginated list of the analysis models you can open in a workspace"
noindex: true
---

```
GET /openapi/memorylake/api/v3/workspaces/{workspaceId}/analysis-models
```

Returns the analysis models in a workspace that you can open. Filter by datasource or template type, and page through the results with continuation tokens.

<Note>
**Permission required:** `analysis_model:read` — models you cannot open are left out of the list rather than the list being refused
</Note>

### Path Parameters

<ParamField path="workspaceId" type="string" required>
Workspace ID
</ParamField>

### Query Parameters

<ParamField query="db_datasource_id" type="string">
Only return models built on this datasource
</ParamField>

<ParamField query="type" type="string">
Only return models of this template type, for example `ASK_DATA`. See [List Analysis Model Templates](/features/memorylake/api-reference/database/analysis-models/list-analysis-model-templates).
</ParamField>

<ParamField query="page_size" type="integer" default="20">
Number of models to return per page, from 1 to 100
</ParamField>

<ParamField query="continuation_token" type="string">
Token from a previous response to fetch the next page. Omit it for the first page.
</ParamField>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.ai/openapi/memorylake/api/v3/workspaces/ws-8001856949ad4f6a5b6226f415ffa877/analysis-models?db_datasource_id=dbds-4b8e2f6a1c9d4e7b8a3f5c2d6e9b1a7c&page_size=20' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### Response

<ResponseField name="data" type="object">
<Expandable title="Paginated analysis model list">
  <ResponseField name="items" type="array">
  Array of analysis model objects
  <Expandable title="Analysis model object">
    <ResponseField name="id" type="string">Analysis model identifier. Treat it as an opaque string.</ResponseField>
    <ResponseField name="name" type="string">Display name</ResponseField>
    <ResponseField name="description" type="string">Free-form description</ResponseField>
    <ResponseField name="type" type="string">Template the model follows, such as `ASK_DATA`. It decides which kinds of knowledge the model accepts.</ResponseField>
    <ResponseField name="schemas" type="array">Schemas the model covers, inherited from its datasource</ResponseField>
    <ResponseField name="custom_id" type="string">Your own identifier for this model, if you set one</ResponseField>
    <ResponseField name="db_datasource_id" type="string">Datasource the model is built on</ResponseField>
    <ResponseField name="workspace_id" type="string">Workspace the model belongs to</ResponseField>
    <ResponseField name="fork_from" type="string">Model this one was forked from. Absent for a model created from nothing.</ResponseField>
    <ResponseField name="created_at" type="string">Creation timestamp</ResponseField>
    <ResponseField name="updated_at" type="string">Last update timestamp</ResponseField>
  </Expandable>
  </ResponseField>
  <ResponseField name="continuation_token" type="string">
  Token to retrieve the next page. Omitted on the last page.
  </ResponseField>
  <ResponseField name="total" type="integer">
  Total number of matching models across all pages. Omitted when the list is filtered by your permissions; page through with `continuation_token` instead.
  </ResponseField>
</Expandable>
</ResponseField>
