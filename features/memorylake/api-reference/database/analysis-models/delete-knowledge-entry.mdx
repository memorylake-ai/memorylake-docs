---
title: "Delete Knowledge Entry"
description: "Delete one knowledge entry from an analysis model"
noindex: true
---

```
DELETE /openapi/memorylake/api/v3/workspaces/{workspaceId}/analysis-models/{modelId}/entries/{entryId}
```

Deletes one knowledge entry from an analysis model. To take an entry out of use but keep it, call [Disable or Restore Knowledge Entry](/features/memorylake/api-reference/database/analysis-models/disable-knowledge-entry) instead.

Whether an entry can be deleted depends on its kind. [List Analysis Model Templates](/features/memorylake/api-reference/database/analysis-models/list-analysis-model-templates) returns a `delete_validation` for each kind, and the request is refused when the entry does not meet it:

- `ANYWAY`: the entry can always be deleted.
- `LEAF`: only when nothing else hangs off it.
- `ISLAND`: only when it is connected to nothing at all.

Deleting an entry that does not exist, or was already deleted, currently answers `400`.

<Note>
**Permission required:** `analysis_model:modify`
</Note>

</ParamField>

</RequestExample>
