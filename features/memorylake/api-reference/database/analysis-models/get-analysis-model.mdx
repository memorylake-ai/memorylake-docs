---
title: "Get Analysis Model"
description: "Retrieve an analysis model by ID or custom ID"
noindex: true
---

```
GET /openapi/memorylake/api/v3/workspaces/{workspaceId}/analysis-models/{modelId}
```

Retrieves an analysis model by its ID. To look it up by the `custom_id` you set when you created it, set `by_custom_id` to `true` and pass the custom ID as the path parameter.

To read the knowledge the model holds, call [List Knowledge Entries](/features/memorylake/api-reference/database/analysis-models/list-knowledge-entries).

<Note>
**Permission required:** `analysis_model:read`
</Note>

### Path Parameters

<ParamField path="workspaceId" type="string" required>
Workspace ID
</ParamField>

<ParamField path="modelId" type="string" required>
Analysis model ID, or the model's `custom_id` when `by_custom_id` is `true`
</ParamField>

### Query Parameters

<ParamField query="by_custom_id" type="boolean" default="false">
Set to `true` to look up the model by `custom_id` instead of its ID
</ParamField>

<RequestExample>
```bash By model ID
curl -X GET 'https://app.memorylake.ai/openapi/memorylake/api/v3/workspaces/ws-8001856949ad4f6a5b6226f415ffa877/analysis-models/am-9d3f7b1e5a2c4d8f6b0e3a7c9d1f5b2e' \
  -H 'Authorization: Bearer sk_xxxxxx'
```

```bash By custom ID
curl -X GET 'https://app.memorylake.ai/openapi/memorylake/api/v3/workspaces/ws-8001856949ad4f6a5b6226f415ffa877/analysis-models/sales-qa?by_custom_id=true' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### Response

<ResponseField name="data" type="object">
<Expandable title="Analysis model object">
  <ResponseField name="id" type="string">Analysis model identifier. Treat it as an opaque string.</ResponseField>
  <ResponseField name="name" type="string">Display name</ResponseField>
  <ResponseField name="description" type="string">Free-form description</ResponseField>
  <ResponseField name="type" type="string">Template the model follows, such as `ASK_DATA`. It decides which kinds of knowledge the model accepts.</ResponseField>
  <ResponseField name="schemas" type="array">Schemas the model covers, inherited from its datasource</ResponseField>
  <ResponseField name="custom_id" type="string">Your own identifier for this model, if you set one</ResponseField>
  <ResponseField name="db_datasource_id" type="string">Datasource the model is built on</ResponseField>
  <ResponseField name="workspace_id" type="string">Workspace the model belongs to</ResponseField>
  <ResponseField name="fork_from" type="string">Model this one was forked from. Absent for a model created from nothing. It is a record of where the model came from, not a dependency: it keeps naming the source after the source is deleted, and looking that ID up then returns not found.</ResponseField>
  <ResponseField name="created_at" type="string">Creation timestamp</ResponseField>
  <ResponseField name="updated_at" type="string">Last update timestamp</ResponseField>
</Expandable>
</ResponseField>
