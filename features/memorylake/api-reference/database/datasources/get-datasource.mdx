---
title: "Get Datasource"
description: "Retrieve a datasource and its build state by ID or custom ID"
noindex: true
---

```
GET /openapi/memorylake/api/v3/workspaces/{workspaceId}/db-datasources/{datasourceId}
```

Retrieves a datasource, including the schema it covers and the state of its index. To look it up by the `custom_id` you set when you created it, set `by_custom_id` to `true` and pass the custom ID as the path parameter.

A datasource has no `status` field. Read the state of its index from three version fields instead:

| What you see | What it means |
|---|---|
| `build_version` is empty | The index has never been built. |
| `building_version` is non-empty | A build is running. Poll this endpoint until `building_version` is empty again; the build has then finished. |
| `data_version` is non-empty and differs from `build_version` | The index is behind the data. [Build the index](/features/memorylake/api-reference/database/datasources/build-datasource-index) again. |

<Note>
**Permission required:** `db_datasource:read`
</Note>

### Path Parameters

<ParamField path="workspaceId" type="string" required>
Workspace ID
</ParamField>

<ParamField path="datasourceId" type="string" required>
Datasource ID, or the datasource's `custom_id` when `by_custom_id` is `true`
</ParamField>

### Query Parameters

<ParamField query="by_custom_id" type="boolean" default="false">
Set to `true` to look up the datasource by `custom_id` instead of its ID
</ParamField>

<RequestExample>
```bash By datasource ID
curl -X GET 'https://app.memorylake.ai/openapi/memorylake/api/v3/workspaces/ws-8001856949ad4f6a5b6226f415ffa877/db-datasources/dbds-4b8e2f6a1c9d4e7b8a3f5c2d6e9b1a7c' \
  -H 'Authorization: Bearer sk_xxxxxx'
```

```bash By custom ID
curl -X GET 'https://app.memorylake.ai/openapi/memorylake/api/v3/workspaces/ws-8001856949ad4f6a5b6226f415ffa877/db-datasources/sales-ds?by_custom_id=true' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### Response

<ResponseField name="data" type="object">
<Expandable title="Datasource object">
  <ResponseField name="id" type="string">Datasource identifier. Treat it as an opaque string.</ResponseField>
  <ResponseField name="name" type="string">Display name</ResponseField>
  <ResponseField name="description" type="string">Free-form description</ResponseField>
  <ResponseField name="schemas" type="array">The schema this datasource covers. Holds exactly one entry for now and cannot be changed.</ResponseField>
  <ResponseField name="workspace_id" type="string">Workspace this datasource belongs to</ResponseField>
  <ResponseField name="db_connection_id" type="string">Connection this datasource reads through</ResponseField>
  <ResponseField name="custom_id" type="string">Your own identifier for this datasource, if you set one</ResponseField>
  <ResponseField name="table_filter_rule" type="string">Regular expression that selects which tables of the schema are indexed. `.*` takes every table.</ResponseField>
  <ResponseField name="database_count" type="integer">Number of database memories that currently use this datasource. The datasource cannot be deleted while this is greater than zero.</ResponseField>
  <ResponseField name="build_version" type="string">Version of the most recently built index. Empty until the first build finishes.</ResponseField>
  <ResponseField name="building_version" type="string">Version of the index being built right now. Empty when no build is running.</ResponseField>
  <ResponseField name="data_version" type="string">Version of the data, used to tell whether the index is current. When it is set and differs from `build_version`, the index is behind the data and a rebuild is due.</ResponseField>
  <ResponseField name="created_at" type="string">Creation timestamp</ResponseField>
  <ResponseField name="updated_at" type="string">Last update timestamp</ResponseField>
</Expandable>
</ResponseField>
