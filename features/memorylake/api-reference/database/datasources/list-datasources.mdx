---
title: "List Datasources"
description: "Returns a paginated list of the datasources in a workspace that you can open"
noindex: true
---

```
GET /openapi/memorylake/api/v3/workspaces/{workspaceId}/db-datasources
```

Returns the datasources in a workspace that you can open. Filter by connection or by name, and page through the results with continuation tokens.

<Note>
**Permission required:** `db_datasource:read` — datasources you cannot open are left out of the list rather than the list being refused
</Note>

### Path Parameters

<ParamField path="workspaceId" type="string" required>
Workspace ID
</ParamField>

### Query Parameters

<ParamField query="db_connection_id" type="string">
Only return datasources that read through this connection
</ParamField>

<ParamField query="name_fuzzy" type="string">
Only return datasources whose name contains this text (case-insensitive)
</ParamField>

<ParamField query="page_size" type="integer" default="20">
Number of datasources to return per page, from 1 to 100
</ParamField>

<ParamField query="continuation_token" type="string">
Token from a previous response to fetch the next page. Omit it for the first page.
</ParamField>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.ai/openapi/memorylake/api/v3/workspaces/ws-8001856949ad4f6a5b6226f415ffa877/db-datasources?db_connection_id=dbconn-7c1e9a4b2d6f4a8e9b3c5d7f1a2b4c6d&page_size=20' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### Response

<ResponseField name="data" type="object">
<Expandable title="Paginated datasource list">
  <ResponseField name="items" type="array">
  Array of datasource objects
  <Expandable title="Datasource object">
    <ResponseField name="id" type="string">Datasource identifier. Treat it as an opaque string.</ResponseField>
    <ResponseField name="name" type="string">Display name</ResponseField>
    <ResponseField name="description" type="string">Free-form description</ResponseField>
    <ResponseField name="schemas" type="array">The schema this datasource covers. Holds exactly one entry for now and cannot be changed.</ResponseField>
    <ResponseField name="workspace_id" type="string">Workspace this datasource belongs to</ResponseField>
    <ResponseField name="db_connection_id" type="string">Connection this datasource reads through</ResponseField>
    <ResponseField name="custom_id" type="string">Your own identifier for this datasource, if you set one</ResponseField>
    <ResponseField name="table_filter_rule" type="string">Regular expression that selects which tables of the schema are indexed. `.*` takes every table.</ResponseField>
    <ResponseField name="database_count" type="integer">Number of database memories that currently use this datasource</ResponseField>
    <ResponseField name="build_version" type="string">Version of the most recently built index. Empty until the first build finishes.</ResponseField>
    <ResponseField name="building_version" type="string">Version of the index being built right now. Empty when no build is running.</ResponseField>
    <ResponseField name="data_version" type="string">Version of the data, used to tell whether the index is current. When it is set and differs from `build_version`, the index is behind the data and a rebuild is due.</ResponseField>
    <ResponseField name="created_at" type="string">Creation timestamp</ResponseField>
    <ResponseField name="updated_at" type="string">Last update timestamp</ResponseField>
  </Expandable>
  </ResponseField>
  <ResponseField name="continuation_token" type="string">
  Token to retrieve the next page. Omitted on the last page.
  </ResponseField>
  <ResponseField name="total" type="integer">
  Total number of matching datasources across all pages. Omitted when the list is filtered by your permissions; page through with `continuation_token` instead.
  </ResponseField>
</Expandable>
</ResponseField>
