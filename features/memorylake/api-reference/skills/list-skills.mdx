---
title: "List Skills"
description: "Returns a paginated list of the skills in your tenant"
---

```
GET /openapi/memorylake/api/v3/skills
```

Returns the skills created in your tenant, newest first. Built-in skills are not included.

<Note>
**Permission required:** `skill:read` — rows you cannot open are left out of the list rather than the list being refused
</Note>

### Query Parameters

<ParamField query="page_size" type="integer" default="20">
Number of skills per page, from 1 to 100.
</ParamField>

<ParamField query="continuation_token" type="string">
Token returned by the previous call. Omit on the first request.
</ParamField>

<ParamField query="name_fuzzy" type="string">
Fuzzy search by skill name.
</ParamField>

<RequestExample>
```bash First page
curl -X GET 'https://app.memorylake.ai/openapi/memorylake/api/v3/skills?page_size=20' \
  -H 'Authorization: Bearer sk_xxxxxx'
```

```bash Search by name
curl -X GET 'https://app.memorylake.ai/openapi/memorylake/api/v3/skills?name_fuzzy=research' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### Response

<ResponseField name="data" type="object">
<Expandable title="Paginated skill list">
  <ResponseField name="items" type="array">
  Array of skill objects
  <Expandable title="Skill object">
    <ResponseField name="id" type="string">Skill ID. Use it to refer to the skill everywhere else.</ResponseField>
    <ResponseField name="name" type="string">Skill name, unique within your tenant</ResponseField>
    <ResponseField name="display_title" type="string">Title shown in the console</ResponseField>
    <ResponseField name="description" type="string">What the skill does</ResponseField>
    <ResponseField name="latest_version" type="integer">Latest published version number. `0` means no package has been published. Absent when the current state could not be read.</ResponseField>
    <ResponseField name="latest_security_status" type="string">Security review state of the latest version: `pending`, `safe`, `blocked` or `error`. Absent has two meanings — see [Security Review](/features/memorylake/api-reference/skills/overview#security-review).</ResponseField>
    <ResponseField name="created_at" type="string">Creation timestamp</ResponseField>
    <ResponseField name="updated_at" type="string">Last update timestamp</ResponseField>
  </Expandable>
  </ResponseField>
  <ResponseField name="continuation_token" type="string">Token for the next page. Absent or `null` when this is the last page.</ResponseField>
</Expandable>
</ResponseField>
