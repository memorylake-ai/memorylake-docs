---
title: "Get Skill"
description: "Retrieve a skill and the security review state of its latest version"
---

```
GET /openapi/memorylake/api/v3/skills/{id}
```

Returns a single skill. Poll this endpoint after you [create a skill](/features/memorylake/api-reference/skills/create-skill) or [publish a version](/features/memorylake/api-reference/skills/create-skill-version) to see whether the security review has finished: it has once `latest_security_status` is no longer `pending`.

<Note>
**Permission required:** `skill:read`
</Note>

### Path Parameters

<ParamField path="id" type="string" required>
Skill ID
</ParamField>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.ai/openapi/memorylake/api/v3/skills/skill-2b0f5f9f4ea54767822f51f4940c8f24' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### Response

<ResponseField name="data" type="object">
<Expandable title="Skill">
  <ResponseField name="id" type="string">Skill ID</ResponseField>
  <ResponseField name="name" type="string">Skill name</ResponseField>
  <ResponseField name="display_title" type="string">Title shown in the console</ResponseField>
  <ResponseField name="description" type="string">What the skill does</ResponseField>
  <ResponseField name="latest_version" type="integer">Latest published version number. `0` means no package has been published. Absent when the current state could not be read.</ResponseField>
  <ResponseField name="latest_security_status" type="string">Security review state of the latest version: `pending`, `safe`, `blocked` or `error`. Absent has two meanings — see [Security Review](/features/memorylake/api-reference/skills/overview#security-review).</ResponseField>
  <ResponseField name="created_at" type="string">Creation timestamp</ResponseField>
  <ResponseField name="updated_at" type="string">Last update timestamp</ResponseField>
</Expandable>
</ResponseField>

<ResponseExample>
```json Success (200)
{

```
</ResponseExample>
