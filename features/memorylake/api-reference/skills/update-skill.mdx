---
title: "Update Skill"
description: "Change a skill's title or description"
---

```
PATCH /openapi/memorylake/api/v3/skills/{id}
```

Changes a skill's `display_title` and `description`. Only the fields you send are changed. The `name` cannot be changed.

This endpoint does not replace the package. To do that, [publish a new version](/features/memorylake/api-reference/skills/create-skill-version). A request that includes `package_ref` or `changelog` is refused with `400`.

<Note>
**Permission required:** `skill:modify`
</Note>

### Path Parameters

<ParamField path="id" type="string" required>
Skill ID
</ParamField>

### Request Body

<ParamField body="display_title" type="string">
New title shown in the console, up to 500 characters.
</ParamField>

<ParamField body="description" type="string">
New description.
</ParamField>

<RequestExample>
```bash cURL
curl -X PATCH 'https://app.memorylake.ai/openapi/memorylake/api/v3/skills/skill-2b0f5f9f4ea54767822f51f4940c8f24' \
  -H 'Authorization: Bearer sk_xxxxxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "description": "Pulls filings, price history and analyst consensus, and drafts an equity research note"
  }'
```
</RequestExample>

### Response

Returns the updated skill, in the same shape as [Get Skill](/features/memorylake/api-reference/skills/get-skill).

<ResponseExample>
```json Success (200)
{
  "success": true,
  "data": {
    "id": "skill-2b0f5f9f4ea54767822f51f4940c8f24",
    "name": "equity-research",
    "display_title": "Equity Research",
    "description": "Pulls filings, price history and analyst consensus, and drafts an equity research note",
    "latest_version": 1,
    "latest_security_status": "safe",
    "created_at": "2026-08-21T09:12:44Z",
    "updated_at": "2026-09-02T11:20:31Z"
  }
}
```
</ResponseExample>
