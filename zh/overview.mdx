## 平台概览

MemoryLake AI 提供统一的模型路由和多模态任务入口，兼容主流协议和渠道，帮助您在生产环境中高效、安全地集成 AI 能力。

## 核心能力

- **统一入口**：兼容 OpenAI、Claude、Gemini 等主流协议，无需修改现有客户端代码
- **智能路由**：自动选择最优渠道，支持重试和容错，保障服务稳定性
- **精细管控**：Token 额度管理、配额分配和用量统计，满足企业级需求
- **团队协作**：支持多用户协作、基于角色的权限管理和邀请管理，适合团队使用

## 入门指南

1) **获取 Token**：在[控制台](https://app.memorylake.ai/panel)生成 API Key，设置配额和过期时间。
2) **浏览文档**：选择模型路由或团队协作开始探索。
3) **首次 API 调用**：参考[模型路由文档](/zh/features/model-router/overview)完成首次 API 调用。
4) **深入了解**：查阅各功能模块的详细文档，了解更多高级能力。
