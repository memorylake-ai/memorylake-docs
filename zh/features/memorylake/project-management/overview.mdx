## 概述

项目帮助您将相关文档和记忆组织成统一的单元。为 AI 交互和团队协作提供结构化的上下文。

## 什么是项目？

MemoryLake 中的项目是：
- **容器**：用于存放相关文档
- **上下文提供者**：通过 MCP 服务器为 AI 模型提供上下文
- **组织单元**：用于知识管理
- **协作空间**：用于团队协作

## 项目组成

### 文档
关联云盘中的文件和文件夹。文档提供 AI 模型可以读取和分析的内容。

### 记忆
添加知识片段和上下文，引导 AI 对项目的理解。

### MCP 服务器
生成 API 密钥，供外部应用程序和 AI 模型访问项目数据。
