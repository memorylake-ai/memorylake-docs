## 仪表板概述

项目仪表板为您提供项目的全面视图，包括统计数据、文档、记忆和 MCP 服务器。

{/* SCREENSHOT: Complete project dashboard */}

## 统计卡片

一目了然地查看关键指标：

**文档数量**：已关联文档的数量

**记忆数量**：记忆的数量

**MCP 服务器数量**：活跃 API 密钥的数量

{/* SCREENSHOT: Statistics cards section */}

## 内联编辑

直接从仪表板编辑项目详情：

1. 点击项目名称 — 变为可编辑状态
2. 输入新名称
3. 按 Enter 保存

描述字段同理。

{/* SCREENSHOT: Inline editing interface */}

## 标签页导航

仪表板包含三个标签页：

### 文档标签页
- 已关联文档列表
- 文档状态（pending、running、okay、error）
- 添加/移除文档
- 查看处理错误

### 记忆标签页
- 项目记忆列表
- 创建/编辑/删除记忆
- 查看记忆内容

### MCP 服务器标签页
- API 密钥列表
- 生成新密钥
- 查看端点 URL
- 删除密钥

{/* SCREENSHOT: Tab navigation */}

## 快捷操作

从仪表板您可以：
- 添加文档
- 创建记忆
- 生成 API 密钥
- 编辑项目详情
- 返回项目列表
