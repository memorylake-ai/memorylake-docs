## 什么是 MemoryLake？

MemoryLake 是一个功能强大的知识管理平台，帮助您组织文档、构建知识库，并通过 UI 和 API 接口为您的信息提供上下文访问。无论是管理研究材料、构建团队知识库，还是将 AI 与您的文档集成，MemoryLake 都能提供所需的工具。

## 核心能力

### 文档存储与组织

- **层级文件系统**：在文件夹和子文件夹中组织文档，支持无限嵌套
- **文件上传**：上传单个文件或整个文件夹，保留目录结构
- **富文本评论**：为任意文件或文件夹添加 Markdown 格式的评论
- **树形导航**：直观的文件浏览器，支持拖放和可调整列宽
- **文件操作**：创建、重命名、移动、删除和下载文件，完整的 CRUD 支持

### 外部服务集成

- **连接器框架**：可扩展架构，支持集成多种文档服务
- **OAuth 认证**：通过标准 OAuth 2.0 流程安全连接外部服务
- **挂载点**：像访问本地文件一样访问外部文档库
- **当前支持**：WPS（金山办公），框架已支持 Dropbox、飞书等更多服务

### 基于项目的组织

- **项目管理**：创建项目，将相关文档和记忆分组
- **文档关联**：通过树形选择器将文件库中的文档关联到项目
- **统计面板**：一目了然地查看文档数量、记忆数量和 MCP 服务状态
- **行内编辑**：直接在面板中更新项目名称和描述

### 记忆知识上下文

- **文本存储**：将笔记、指南和上下文信息作为记忆存储
- **项目范围**：每条记忆属于一个项目，为该项目提供上下文
- **CRUD 操作**：通过简洁的界面创建、读取、更新和删除记忆
- **AI 集成**：记忆为通过 MCP 服务访问您项目的 AI 模型提供上下文

### 编程访问

- **MCP 服务端点**：为 AI 模型和外部应用生成认证 URL
- **API Key 管理**：为每个项目创建多个 API Key，安全管理密钥
- **RESTful API**：完整覆盖文件库、项目、记忆和连接器的 API
- **认证方式**：支持基于会话和 API Key 两种认证方式

## 架构概览

MemoryLake 基于现代架构构建，结合了：

- **文档存储**：安全的云端文件和文件夹存储
- **评论层**：丰富的评论系统，增强上下文信息
- **连接器层**：可扩展的外部服务集成框架
- **项目层**：将相关内容分组的组织结构
- **API 层**：RESTful API 和 MCP 服务端点，支持外部访问
- **认证**：安全的认证机制，支持会话管理和 API Key
