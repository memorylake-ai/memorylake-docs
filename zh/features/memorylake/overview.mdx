## 什么是 MemoryLake？

MemoryLake 是面向 AI 应用的记忆平台。您将文档和会话输入其中，它会自动提取结构化事实，供您的 Agent 和应用搜索与检索。可以将它理解为 AI 的长期记忆——持久化、可查询，并按"谁说了什么"进行组织。

MemoryLake 围绕三大支柱构建：

<CardGroup cols={3}>
<Card title="文档记忆" icon="file-lines">
将文件导入项目。MemoryLake 为其建立语义搜索索引，让您的 AI 能在整个知识库中找到相关内容。
</Card>

<Card title="会话记忆" icon="comments">
提交用户与助手的会话。MemoryLake 自动提取结构化事实——偏好、决策、上下文——并将其关联到正确的 Actor。
</Card>

<Card title="统一搜索" icon="magnifying-glass">
通过一次自然语言搜索，同时查询文档和事实。无论信息以何种方式进入系统，都能获取最相关的结果。
</Card>
</CardGroup>

## 资源模型

MemoryLake 按清晰的层级结构组织数据：

```
工作空间（数据隔离边界）
  |
  +-- Actor（参与者身份——HUMAN 或 ASSISTANT）
  |     +-- Actor 事实（每用户记忆，跨项目跟随 Actor）
  |
  +-- 项目（知识容器）
        +-- 文档（导入的文件，已建立搜索索引）
        +-- 会话
        |     +-- 消息（用户与助手的交互）
        +-- 项目事实（提取的知识，作用域限定在本项目）
```

**工作空间**提供数据隔离——类似于租户。每个工作空间拥有独立的 Actor、项目和搜索索引。

**Actor**代表参与者。每个人类用户或 AI 助手都会获得一个 Actor 身份。关于某个 Actor 的事实会跨工作空间内所有项目跟随该 Actor。

**项目**是知识容器。项目中包含文档、会话以及从中提取的事实。通常为每个用例、领域或应用创建一个项目。

## 工作原理

<Steps>
<Step title="摄入">
您通过两个通道将数据引入项目：从文档库导入文档，或通过 API 提交会话。两个通道的数据汇入同一个项目。
</Step>

<Step title="提取">
MemoryLake 自动处理您的内容。文档会被建立语义搜索索引。会话会被分析以提取结构化事实——例如用户偏好、既定目标、决策和上下文。
</Step>

<Step title="搜索">
使用自然语言查询工作空间。MemoryLake 同时搜索文档内容和提取的事实，在一次响应中返回最相关的结果。
</Step>
</Steps>
