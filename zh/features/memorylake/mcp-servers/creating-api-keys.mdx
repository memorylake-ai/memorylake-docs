## 创建 API 密钥

<Steps>
<Step title="打开项目">
导航到项目仪表板。
</Step>

<Step title="前往 MCP 服务器标签页">
点击"MCP 服务器"标签页。

{/* SCREENSHOT: MCP Servers tab */}
</Step>

<Step title="点击添加 MCP 服务器">
点击"添加 MCP 服务器"按钮。

{/* SCREENSHOT: Create MCP server dialog */}
</Step>

<Step title="输入描述">
为此 API 密钥提供描述（可选但建议填写）：
- "Claude AI Integration"
- "Production API Access"
- "Team Member - John"
- "Analytics Dashboard"

这有助于您以后识别密钥。
</Step>

<Step title="生成密钥">
点击"生成"或"创建"来创建 API 密钥。
</Step>

<Step title="立即复制密钥">
**关键步骤**：API 密钥会在对话框中显示。这是您唯一一次看到它的机会！

{/* SCREENSHOT: Secret display with copy button and warning */}

- 点击"复制"将密钥复制到剪贴板
- 将其保存在安全的位置（密码管理器、环境变量）
- 切勿将其提交到版本控制系统

<Warning>
一旦关闭此对话框，完整的密钥将无法再次获取。如果丢失，您必须删除并重新创建 API 密钥。
</Warning>

<Check>
您应该已经复制并安全存储了 API 密钥。
</Check>
</Step>

<Step title="记录端点 URL">
对话框还会显示端点 URL：

```
https://ai.data.cloud/memorylake/mcp/v1?apikey=...
```

复制此 URL 以在您的应用程序中使用。

{/* SCREENSHOT: Endpoint URL display */}
</Step>
</Steps>

## 最佳实践

### 描述性名称

使用清晰的描述：
- ✅ "Production - Claude Integration"
- ✅ "Development - Testing"
- ✅ "Analytics Dashboard - Read Only"
- ❌ "Key 1"
- ❌ "Test"

### 安全存储

安全存储 API 密钥：
- **密码管理器**：1Password、LastPass、Bitwarden
- **环境变量**：`.env` 文件（添加到 `.gitignore`）
- **密钥管理器**：AWS Secrets Manager、Azure Key Vault
- **切勿**：提交到 Git、存储在代码中、通过聊天/邮件分享

### 多个密钥

为不同用途创建独立的密钥：
- 每个环境一个（开发、预发布、生产）
- 每个团队成员一个（便于追溯）
- 每个集成一个（Claude、自定义应用、分析工具）

这样您可以撤销特定的访问权限而不影响其他密钥。

### 密钥轮换

定期轮换密钥：
1. 创建新的 API 密钥
2. 更新应用程序使用新密钥
3. 验证新密钥工作正常
4. 删除旧的 API 密钥

## 管理 API 密钥

### 删除 API 密钥

要撤销访问权限：
1. 点击密钥的删除图标
2. 确认删除

{/* SCREENSHOT: Delete confirmation */}

访问权限立即被撤销。

<Warning>
删除 API 密钥会立即撤销访问权限。使用该密钥的应用程序将收到 401 Unauthorized 错误。
</Warning>

## 故障排除

<AccordionGroup>

<Accordion title="忘记复制密钥">
**解决方案**：您必须删除该 API 密钥并创建一个新的。密钥在创建后无法再次获取。
</Accordion>

<Accordion title="想再次查看完整密钥">
**无法实现**：出于安全考虑，密钥仅显示一次。如果丢失，请删除并重新创建。
</Accordion>

</AccordionGroup>
