## 概述

MCP（模型上下文协议）服务器为外部应用程序和 AI 模型提供安全访问您项目数据的 API 端点。

## 什么是 MCP 服务器？

MemoryLake 中的 MCP 服务器是：
- **API 密钥端点**：用于外部访问的认证 URL
- **项目级别的**：每个 API 密钥提供对一个项目的访问
- **只读的**：外部访问无法修改您的数据
- **安全的**：API 密钥仅在创建时显示一次

## 工作原理

<Steps>
<Step title="生成 API 密钥">
为您的项目创建一个 API 密钥，可附带可选描述。
</Step>

<Step title="复制密钥">
**重要提示**：请立即复制 API 密钥 — 它仅显示一次！
</Step>

<Step title="使用端点">
使用提供的端点 URL 和您的 API 密钥访问项目数据。
</Step>

<Step title="安全存储">
将您的 API 密钥安全存储（切勿提交到版本控制系统）。
</Step>
</Steps>

## MCP 服务器提供的访问内容

使用 API 密钥时，外部应用程序可以读取：
- **关联文档**：文件列表和内容
- **记忆**：项目中的所有记忆
- **文档评论**：附加到文件的评论

<Warning>
MCP 服务器提供只读访问权限。外部应用程序无法修改、删除或上传内容。
</Warning>
