## 概述

MemoryLake 的文档管理系统为您提供了强大且直观的文件和文件夹组织界面。它基于层级文件系统，融合了传统文件浏览器的熟悉操作体验和现代云存储的先进功能。

## 主要功能

### 层级组织

- **无限嵌套**：在文件夹中创建子文件夹，无深度限制
- **可视化树形结构**：一目了然地查看整个文档层级
- **文件夹展开/折叠**：展开和折叠文件夹，聚焦相关内容
- **面包屑导航**：随时了解您在文档树中的位置

{/* SCREENSHOT: Document tree showing multiple levels of folder hierarchy */}

### 文件上传与管理
- **多种上传方式**：
  - 单文件选择
  - 多文件选择
  - 整个文件夹上传并保留目录结构
  - 从桌面拖拽上传

- **可靠上传**：
  - 支持任意大小的文件
  - 可同时上传多个文件
  - 实时进度跟踪
  - 中断后可恢复上传

- **支持的文件类型**：
  - 文档：PDF、Microsoft Word
  - 电子表格：Microsoft Excel、CSV、TSV
  - 演示文稿：Microsoft PowerPoint
  - 文本：纯文本、Markdown
  - 图片：PNG、JPEG、GIF、BMP、WebP、TIFF

<Tip>
MemoryLake 自动可靠地处理大文件上传。
</Tip>

### 文件操作
支持所有标准文件操作：
- **创建**：在层级结构中的任意位置新建文件夹
- **读取**：下载文件到本地查看
- **更新**：重命名文件和文件夹、移动项目
- **删除**：删除文件和文件夹（需确认）

### 评论
- **Markdown 评论**：添加包含格式、列表和链接的富文本评论
- **实时预览**：输入时即时查看 Markdown 渲染效果
- **自动保存**：草稿保护，防止数据丢失

{/* SCREENSHOT: Comment panel with Markdown editor and preview */}

### 树形视图功能
- **可调节界面**：调整树形面板宽度以适应您的工作流程
- **右键菜单**：右键快速访问各项操作

## 常见工作流程

<AccordionGroup>
<Accordion title="整理研究资料">
1. 创建项目文件夹结构（例如 "Research/Topic/Sources"）
2. 使用文件夹上传功能保留目录结构
3. 为关键文档添加 Markdown 评论，包含摘要或见解
4. 将文件夹关联到项目以供 AI 访问
</Accordion>

<Accordion title="团队文档库">
1. 为每个团队或部门创建文件夹
2. 上传共享文档和资源
3. 使用元数据按类别或状态标记文档
4. 连接 WPS 等外部服务获取额外内容
</Accordion>

<Accordion title="知识库建设">
1. 按主题在清晰的文件夹结构中组织文档
2. 添加富文本 Markdown 评论说明上下文和关联关系
3. 批量上传相关文档
4. 创建项目将相关文档归组
5. 生成 MCP 服务器密钥以供 AI 访问您的知识库
</Accordion>

<Accordion title="从外部服务迁移">
1. 从外部服务下载文档结构
2. 使用文件夹上传功能保留目录结构导入
3. 通过进度跟踪确认所有文件已成功上传
4. 根据需要添加元数据和评论
5. 通过连接器直接连接外部服务，以实现后续同步
</Accordion>
</AccordionGroup>

## 支持的文件格式

MemoryLake 可解析和索引以下文档类型：

- **PDF** — 便携式文档格式
- **Microsoft Word** — Word 文档和模板
- **Microsoft Excel** — Excel 工作簿和模板，以及 CSV 和 TSV 数据
- **Microsoft PowerPoint** — PowerPoint 演示文稿和模板
- **文本和 Markdown** — 纯文本和 Markdown 笔记
- **图片** — PNG、JPEG、GIF、BMP、WebP 和 TIFF

## 安全与权限

- **用户隔离**：您的云盘对您的账户私有
- **项目共享**：通过项目关联和 MCP 服务器共享访问权限

## 性能

MemoryLake 针对高效处理大型文档集合进行了优化，即使有数千个文件也能确保流畅运行。

## 与其他功能的集成

文档管理与 MemoryLake 的其他功能无缝集成：

- **项目**：将文档关联到项目进行组织管理
- **连接器**：将外部文档服务挂载到您的文件树中
- **MCP 服务器**：为 AI 模型提供对文档的只读访问权限
- **记忆**：将记忆链接到特定文档以提供上下文

## 最佳实践

<AccordionGroup>
<Accordion title="文件夹组织">
- 使用清晰、描述性的文件夹名称
- 将相关文档归组在一起
- 避免过度嵌套（3-5 层为最佳）
- 在相似项目之间创建一致的结构
</Accordion>

<Accordion title="文件命名">
- 使用能描述内容的文件名
- 相关时使用 ISO 格式日期（YYYY-MM-DD）
- 避免可能导致问题的特殊字符
- 在项目或文件夹内保持一致性
</Accordion>

<Accordion title="元数据使用">
- 为需要上下文的文档添加评论
- 使用 Markdown 格式提高可读性
- 包含相关文档的链接
- 当文档用途变更时更新评论
</Accordion>

<Accordion title="性能提示">
- 批量上传文件夹而非逐个上传文件
- 使用文件夹上传保留目录结构
- 利用懒加载功能，避免一次性展开所有文件夹
- 定期清理不再使用的文件
</Accordion>
</AccordionGroup>

<Tip>
从简单的文件夹结构开始，根据需要逐步扩展。先简后繁比先繁后简要容易得多。
</Tip>
