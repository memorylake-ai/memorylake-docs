## 概述

使用 Markdown 格式的评论为您的文档添加上下文信息。提供有助于人类和 AI 理解内容的上下文。

## Markdown 评论

### 评论系统概述

MemoryLake 的评论系统使用 Markdown，让您可以为任何文件或文件夹创建富文本格式的笔记。

**功能特点**：
- **Markdown 格式化**：标题、列表、粗体、斜体、代码块、链接
- **实时预览**：输入时即时查看渲染效果
- **自动保存**：草稿保护，防止数据丢失

{/* SCREENSHOT: Markdown comment editor with split preview */}

### 创建评论

<Steps>
<Step title="打开评论编辑器">
选择一个文件或文件夹，打开评论面板（通常在右侧）。
</Step>

<Step title="编写评论">
使用 Markdown 编辑器撰写您的评论。您可以使用：
- `# Headers` 用于结构化
- `**bold**` 和 `*italic*` 用于强调
- `- Lists` 用于组织内容
- `` `code` `` 用于技术术语
- `[links](url)` 用于引用
</Step>

<Step title="预览内容">
实时预览面板显示您的 Markdown 将如何渲染。

{/* SCREENSHOT: Side-by-side editor and preview */}

<Tip>
在保存前使用预览功能确认格式，特别是包含表格或代码块等复杂 Markdown 时。
</Tip>
</Step>

<Step title="保存评论">
点击"保存"将评论存储到文件中。
</Step>
</Steps>

### Markdown 语法参考

以下是常用 Markdown 格式的快速参考：

#### 标题

```markdown
# H1 Header
## H2 Header
### H3 Header
```

#### 文本格式

```markdown
**Bold text**
*Italic text*
~~Strikethrough~~
`Inline code`
```

#### 列表

```markdown
Unordered list:
- Item 1
- Item 2
  - Nested item

Ordered list:
1. First item
2. Second item
3. Third item
```

#### 链接和图片

```markdown
[Link text](https://example.com)
![Image alt text](https://example.com/image.png)
```

#### 代码块

````markdown
```javascript
function example() {
  return "Code with syntax highlighting";
}
```
````

#### 引用

```markdown
> This is a quoted text
> It can span multiple lines
```

#### 表格

```markdown
| Column 1 | Column 2 | Column 3 |
|----------|----------|----------|
| Data 1   | Data 2   | Data 3   |
| Data 4   | Data 5   | Data 6   |
```

## 评论管理

### 编辑评论

要修改已有评论：
1. 选择文件或文件夹
2. 打开评论面板
3. 编辑 Markdown 文本
4. 保存更改

### 删除评论

要完全删除评论：
1. 打开评论编辑器
2. 删除所有文本
3. 点击"保存"

<Warning>
删除评论是永久性的，无法撤销。如果您以后可能需要这些信息，建议添加"已弃用"标题代替删除。
</Warning>

## 最佳实践

<AccordionGroup>
<Accordion title="编写有效的评论">
**应该做的**：
- 简洁但完整
- 使用标题组织长评论
- 包含他人可能不了解的上下文
- 链接到相关文档
- 当内容变更时更新评论

**不应该做的**：
- 编写过长的评论（保持易于浏览）
- 在共享文件的评论中包含敏感信息
- 重复文件本身已有的信息
- 保留过时的评论
</Accordion>


<Accordion title="Markdown 格式化技巧">
- 使用 `#` 标题创建结构
- 列表使内容易于浏览
- **加粗**关键术语以快速识别
- 代码块用于技术内容
- 表格用于结构化数据
- 链接用于连接相关文档
</Accordion>

<Accordion title="无障碍访问">
- 按层级顺序使用标题（先 H1，再 H2，而非直接从 H1 到 H3）
- 提供描述性的链接文本（而非"点击这里"）
- 为图片添加替代文本
- 保持语言清晰简洁
- 使用列表以提升屏幕阅读器支持
</Accordion>
</AccordionGroup>

## 与项目的集成

评论增强了项目工作流程：

- **项目上下文**：当文档关联到项目时，评论提供上下文信息
- **AI 理解**：通过 MCP 服务器访问的 AI 模型可以阅读评论以理解文档用途
- **团队协作**：评论帮助团队成员了解文档关系和历史
- **搜索**：评论可被搜索，使文档更容易被找到
