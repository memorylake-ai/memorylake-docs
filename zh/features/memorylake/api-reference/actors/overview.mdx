---
title: "概述"
description: "Actor 是 MemoryLake 的身份层 — 所有记忆的主体"
---

**Actor** 代表 MemoryLake 中的参与者身份。会话中的每条消息都归属于一个 actor，从对话中提取的每个事实都与之关联。Actor 是**记忆的主体** — 它是 MemoryLake "记住的对象"。

## Actor 类型

Actor API 面向的是使用您的应用的**人**。您在这里创建的 actor 就是一个人，没有别的类型可选。

**Agent 不能通过这套 API 访问。** Agent 也有自己的记忆，但要通过 [Agent](/zh/features/memorylake/api-reference/agents/overview) 相关端点、用 Agent 的 id 来访问。这里不会返回任何属于 Agent 的东西，传入不是 actor 的 id 会得到 `404`。

<Note>
  如果您此前通过 Agent 的身份 actor 读取它的记忆，请改用 agent id。记忆是同一份，只是改用和其他地方一致的称呼方式。
</Note>

## 工作流程

1. **创建** actor，使用 `custom_id` 映射到您系统中的用户 ID
2. **绑定** actor 到一个或多个工作空间
3. **使用** actor 的 ID [追加消息](/zh/features/memorylake/api-reference/conversations/create-message)到会话中
4. **查询** actor 积累的事实，通过 [Actor 事实](/zh/features/memorylake/api-reference/facts/list-actor-facts)

## 事实存储在哪里

MemoryLake 在三个范围上保存事实。一条事实属于哪个范围，决定了您从哪里把它读回来：

| 范围 | 记住的是 | 从哪里读 |
|---|---|---|
| **Actor 事实** | 某个人，跨工作空间内的所有项目。*"Jane 偏好深色模式"* | `/workspaces/{workspaceId}/actors/{actorId}/facts` |
| **Agent 事实** | 某个 Agent，跨工作空间内的所有项目。*"这个 Agent 用法语回答"* | `/workspaces/{workspaceId}/agents/{agentId}/facts` |
| **项目事实** | 某一个项目，不论由谁贡献。*"Q1 营收为 1250 万美元"* | `/workspaces/{workspaceId}/projects/{projectId}/memories/facts` |

Actor 与 Agent 的事实会跟着各自的主体跨项目走——这正是让每个人、每个 Agent 在您的应用里各自拥有记忆的机制。项目事实则留在项目里。

<Note>
  **Agent 的事实要用它的 agent id、在 agent 上读**，不是通过上面的 actor 端点。两条路径是对称的：对人的事实能做的操作，对 Agent 的事实同样能做，区别只在 id 和路径。
</Note>

| 操作 | 方法 | 路径 |

| [删除 Actor](/zh/features/memorylake/api-reference/actors/delete-actor) | `DELETE` | `/api/v3/actors/{id}` |
