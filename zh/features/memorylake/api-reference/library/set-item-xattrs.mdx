---
title: "设置项目扩展属性"
description: "在资料库项上附加或更新自定义键值元数据"
---

```
PUT /openapi/memorylake/api/v1/drives/items/{item_id}/xattrs
```

在资料库的文件或文件夹上存储你自己的字符串键值对（扩展属性，即 *xattrs*）。使用此功能可以为项标记你的应用所关注的元数据 — 例如租户 ID、工作流状态或内容分类 — 而无需更改文件本身。

此调用会与项上已有的 xattrs **合并**：你发送的键会被添加或覆盖；项上已有但你未发送的键保持不变。要移除某个键，请调用[删除项目扩展属性](/zh/features/memorylake/api-reference/library/delete-item-xattrs)。

<Note>
系统保留了一些自行管理的内部 xattr 键。为这些键发送值不会产生任何效果 — 它们会被静默过滤。系统根文件夹（`My Space`、`WPS Space`、`Lark Space`）完全拒绝 xattr 写入并返回 `403`。
</Note>

<Note>
**所需权限：** [`drive:item_modify`](/features/team-collaboration/permission-reference#edit-your-files) · `service`
</Note>

### 路径参数

<ParamField path="item_id" type="string" required>
要设置 xattrs 的文件或文件夹的 ID。
</ParamField>

### 请求体

<ParamField body="x_attrs" type="object" required>
要更新插入到项上的 `字符串 → 字符串` 映射。每个条目是一个扩展属性。允许传入空映射，但不会产生任何操作。
</ParamField>

<RequestExample>
```bash cURL
curl -X PUT 'https://app.memorylake.ai/openapi/memorylake/api/v1/drives/items/sc-5c6bf0f82d624a20a6fa4696997bdd46:7d8cf1e93f634b31b5/xattrs' \
  -H 'Authorization: Bearer sk_xxxxxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "x_attrs": {
      "tenant_id": "acme-corp",
      "review_status": "approved"
    }
  }'
```
</RequestExample>

### 响应

<ResponseField name="success" type="boolean">表示请求是否成功</ResponseField>
<ResponseField name="message" type="string">人类可读的状态消息</ResponseField>

<ResponseExample>
```json Success (200)
{
  "success": true,
  "message": "Operation completed successfully"
}
```
</ResponseExample>

<Tip>
要读取项上当前的 xattrs，请调用[获取项目](/zh/features/memorylake/api-reference/library/get-item) — 其响应包含完整的 `x_attrs` 映射。
</Tip>
