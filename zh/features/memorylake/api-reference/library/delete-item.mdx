---
title: "删除项目"
description: "从资料库中删除文件或文件夹（对文件夹递归删除）"
---

```
DELETE /openapi/memorylake/api/v1/drives/items/{item_id}
```

永久删除文件或文件夹。删除文件夹时会**递归删除其中的所有内容**。

<Warning>
此操作具有破坏性且不可逆。如果目标是文件夹，其下的所有文件和子文件夹都将被移除。调用此接口前请向用户确认。
</Warning>

<Note>
删除被一个或多个项目文档引用的文件时，不会自动移除这些文档。如果你希望文档从项目中消失，请先调用[移除文档](/zh/features/memorylake/api-reference/memories/remove-documents)。
</Note>

<Note>
**所需权限：** [`drive:item_delete`](/features/team-collaboration/permission-reference#delete-files) · `service`
</Note>

### 路径参数

<ParamField path="item_id" type="string" required>
要删除的具体项目 ID。工作空间根目录（`MY_SPACE`）不能被删除。
</ParamField>

<RequestExample>
```bash cURL
curl -X DELETE 'https://app.memorylake.ai/openapi/memorylake/api/v1/drives/items/sc-5c6bf0f82d624a20a6fa4696997bdd46:7d8cf1e93f634b31b5' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### 响应

<ResponseField name="success" type="boolean">表示请求是否成功</ResponseField>
<ResponseField name="message" type="string">人类可读的状态消息</ResponseField>

<ResponseExample>
```json Success (200)
{
  "success": true,
  "message": "Operation completed successfully"
}
```
</ResponseExample>
