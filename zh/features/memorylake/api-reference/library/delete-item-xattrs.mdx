---
title: "删除项目扩展属性"
description: "从资料库项中移除指定的扩展属性键"
---

```
DELETE /openapi/memorylake/api/v1/drives/items/{item_id}/xattrs?key={comma-separated-keys}
```

从资料库的文件或文件夹中移除一个或多个扩展属性键。仅你列出的键会被移除；项上的其他 xattrs 保持不变。

<Warning>
此操作不可逆。调用后，列出的 xattr 值将被永久删除。项本身**不受影响** — 仅移除列出的元数据键。
</Warning>

<Note>
系统保留的 xattr 键不能被删除；在 `key` 列表中包含它们将被拒绝。系统根文件夹（`My Space`、`WPS Space`、`Lark Space`）完全拒绝 xattr 删除并返回 `403`。
</Note>

<Note>
**所需权限：** [`drive:item_modify`](/features/team-collaboration/permission-reference#edit-your-files) · `service`
</Note>

### 路径参数

<ParamField path="item_id" type="string" required>
要移除 xattrs 的文件或文件夹的 ID。
</ParamField>

### 查询参数

<ParamField query="key" type="string" required>
要删除的 xattr 键的逗号分隔列表，例如 `key=tenant_id,review_status`。至少需要一个键。
</ParamField>

<RequestExample>
```bash cURL
curl -X DELETE 'https://app.memorylake.ai/openapi/memorylake/api/v1/drives/items/sc-5c6bf0f82d624a20a6fa4696997bdd46:7d8cf1e93f634b31b5/xattrs?key=tenant_id,review_status' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### 响应

<ResponseField name="success" type="boolean">表示请求是否成功</ResponseField>
<ResponseField name="message" type="string">人类可读的状态消息</ResponseField>

<ResponseExample>
```json Success (200)
{
  "success": true,
  "message": "Operation completed successfully"
}
```
</ResponseExample>

<Tip>
要验证操作后项上剩余的 xattrs，请调用[获取项目](/zh/features/memorylake/api-reference/library/get-item) — 其响应包含当前的 `x_attrs` 映射。
</Tip>
