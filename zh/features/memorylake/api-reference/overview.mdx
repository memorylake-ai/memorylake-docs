## API 概览

MemoryLake API 提供对资料库、项目管理、文档搜索和记忆提取的编程访问。您可以使用它构建自定义集成、自动化工作流程并扩展平台功能。

## 基础 URL

```
https://app.memorylake.ai/openapi/memorylake
```

<Note>
请将 `app.memorylake.ai` 替换为您实际的 MemoryLake 实例域名。
</Note>

## 认证

所有 API 请求都需要通过 Bearer 令牌进行认证。详情请参阅[认证](/zh/features/memorylake/api-reference/authentication)。

## 通用模式

### 响应格式

所有响应遵循以下结构：

```json
{
  "success": true,
  "message": "Operation completed successfully",
  "data": {
    // Response payload
  }
}
```

错误响应：
```json
{
  "success": false,
  "message": "Error description",
  "error_code": "ERROR_CODE"
}
```

### 分页

列表接口支持分页：

**查询参数**：
- `page`：页码（默认：1）
- `size`：每页条数（默认：20，最大：100）

### 时间戳

所有时间戳使用 ISO 8601 格式：
```
2024-01-15T10:30:00Z
```
