## 什么是 API Key？

API Key 是您访问 Model Router 的身份验证凭据。它类似于一个密码，允许您向 API 发送请求。每个 API Key 都关联到一个特定的分组，该分组控制您可以访问哪些模型以及拥有多少配额。

## 如何创建 API Key

### 步骤 1：进入 API Key 管理页面

1. 登录 [Memorylake 控制台](https://app.memorylake.ai)
2. 点击"API Keys"或导航到 [API Key 管理页面](https://app.memorylake.ai/panel/token)

### 步骤 2：创建新的 API Key

1. 点击"创建 API Key"按钮
2. 为您的 API Key 输入一个名称（仅供您参考）
3. 配置以下设置：
   - **名称**：选择任意名称（例如"我的项目 API Key"）
   - **配额**：如果不想设置限制，可设为无限制；或设置一个具体的额度
   - **分组**：选择 API Key 分组（这决定了可以使用哪些模型）

<Info>
API Key 名称仅供您参考，之后可以随时更改。配额设置控制您在需要充值之前可以使用的额度。
</Info>

### 步骤 3：保存您的 API Key

创建 API Key 后，您将看到一个以 `sk-` 开头的密钥。**重要提示**：请立即复制并保存此密钥，关闭对话框后将无法再次查看。

<Warning>
请确保将 API Key 保存在安全的地方。如果丢失，您需要创建一个新的密钥。切勿公开分享您的 API Key 或将其提交到版本控制系统中。
</Warning>
