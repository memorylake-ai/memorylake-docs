## 快速介绍

模型路由提供统一的模型路由和多模态任务入口，兼容主流协议和渠道。

- 一个入口覆盖主流模型和任务，兼容 OpenAI 风格调用，无需更换 SDK
- 保留 Claude、Gemini 等原生路径，降低迁移和切换成本
- 内置稳定性保障、配额结算、通知和安全策略，帮助您在生产环境中放心集成

## 快速开始

1. **[创建 API Key](/features/model-router/getting-started/create-api-key)**：在控制台生成 API Key
2. **[查看可用模型](/features/model-router/list-available-models)**：了解可以使用哪些模型
3. **[使用 API Key](/features/model-router/getting-started/use-api-key/overview)**：选择 API 调用方式
4. **[监控用量](/features/model-router/view-usage-and-billing)**：追踪 API 使用和计费
