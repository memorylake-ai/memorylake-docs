## 快速介绍

团队协作功能帮助您管理共享 API 端点、配额和日志，实现多用户协作，同时保持清晰的访问控制。

- 与同事共享 API 端点、配额和日志，同时保持清晰的访问控制
- 通过链接或邮箱即时邀请成员，支持撤销或重新发送邀请
- 为成员分配独立配额，查看团队用量和排行
- 在个人和团队上下文之间切换，确保调用遵循当前上下文

## 权限目录

每项权限按功能区域分组。点击能力名称可跳转到[权限参考](/features/team-collaboration/permission-reference)中的完整描述。

每行带有一个 **Level** 标签，取自 OpenAPI 授权矩阵：

- `instance` — 可授予特定资源实例（例如某个项目）。管理员可以将其授予项目 A 而不授予项目 B。
- `service` — 适用于整个资源类型。一旦授予，将覆盖团队中该资源的所有实例。
